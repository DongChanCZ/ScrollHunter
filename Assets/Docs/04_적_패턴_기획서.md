### 3.1 잡몹 A — 초록 전담 (기본)

```
0.0s  캐스팅 시작 · 🟢 초록 · 스킬명 표시
2.5s  발동 — 일반 피해 30
3.0s  경직 해제
3.5s  다음 캐스팅 시작
```

| 항목 | 값 | 근거 |
|---|---|---|
| 캐스팅 길이 | 2.5초 | 가장 길다. 최초 학습 단계라 여유 확보 |
| 피해량 | 30 | 2단계 구현값. 30×100/120 = 실피해 **25** (정확값) |
| 대응 | 불필요 | **"대응할 필요가 없는 공격"을 먼저 보여줘야 주황·빨강의 특별함이 성립** |

### 3.2 잡몹 B — 주황 전담 (차단 학습)

```
0.0s  캐스팅 시작 · 🟠 주황 · 경고음 · 좌측 상단에 스킬 설명 표시
      └ 이 구간 전체(0.0~3.0s)에서 차단 카드 유효
3.0s  발동 — 기절 [ ]초
3.5s  경직 해제
4.0s  다음 캐스팅 시작
```

| 항목 | 값 | 근거 |
|---|---|---|
| 캐스팅 길이 | 3.0초 | 차단 카드를 손패에서 찾고 코스트를 확인할 시간 |
| 피해량 | 40 | 2단계 구현값. 실피해 **33** (40×100/120=33.33 → 반올림). 기절은 3단계 이후 |
| 미대응 시 | 기절 [ ]초 | [ 기절 중 코스트 충전 여부는 02 문서 E09 참조 ] |
| 차단 성공 시 | 캐스팅 취소 + 경직 [ ]초 | [ ] |
| 등장 시 튜토리얼 | [ 첫 등장 시 1회 안내 표시 / 없음 ] | [ ] |

### 3.3 잡몹 C — 빨강 전담 (방어도 학습)

```
0.0s  캐스팅 시작 · 🔴 빨강 · 경고음(다른 음높이) · 화면 가장자리 붉은 비네트
      └ 이 구간 전체에서 방어 카드 유효
4.0s  발동 — 대형 피해 150
4.8s  경직 해제
5.0s  다음 캐스팅 시작
```

| 항목 | 값 | 근거 |
|---|---|---|
| 캐스팅 길이 | 4.0초 | 가장 길다. 방어도 카드를 끌어올 시간까지 고려 |
| 피해량 | 150 | 방어도 120(09 문서 3단계)보다 크게 → 완전 방어 불가. 150×100/120 = 실피해 **125** (정확값) |
| 차단 가능 여부 | **불가** | 빨강은 차단이 아닌 방어로 대응해야 함을 학습시킴 |
| 미대응 시 | HP의 **25**% 손실 | 실피해 125 / 최대 HP 500. 즉사는 아니되 다음 전투가 위태로울 정도 |

### 3.4 잡몹 D — 주황 + 빨강 (선택 강요)

```
[패턴 1] 🟠 주황 · 캐스팅 2.5s · 기절
[패턴 2] 🔴 빨강 · 캐스팅 3.5s · 대형 피해

순서: 1 → 2 → 1 → 2 (교대)
2체 등장 시 서로 0.5초 이상 간격 (02 문서 §9)
```

| 항목 | 값 | 근거 |
|---|---|---|
| 2체 동시 등장 | D × 2 (인카운터 4) | **주황과 빨강이 겹치면 코스트가 부족해진다** — 이 곡선의 목표 지점 |
| 캐스팅 겹침 설계 | [ 의도적으로 1.0초 차이로 겹치게 배치 ] | 하나만 막을 수 있는 상황을 강제 |
| 플레이어의 선택 | 기절을 감수할 것인가, 대형 피해를 감수할 것인가 | [ ] |
