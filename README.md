# ScrollHunter
게임 ScrollHunter를 Git으로 관리하는 Repository 입니다.

## Web 빌드

현재 Web_Build 브랜치는 itch.io용 PC 브라우저 빌드입니다. 웹 시작 화면과 게임 옵션에서 한국어·English·日本語·简体中文·Español을 고릅니다. 처음 실행하면 영어가 기본이며, 저장한 언어가 있으면 그 값을 사용합니다. 기존 영문 타이틀·클리어 문구는 유지합니다.

- 빌드: Unity 메뉴 Tools > Scroll Hunter > Build Web 1.2
- 출력: 바탕화면 ScrollHunter_Web_1.2
- 업로드·실행: [Docs/09](Docs/09_프로토타입_제작절차.md#web-language-20261014)
- 최신 빌드·검사: [Docs/07](Docs/07_개발일지.md#web-1-2-20261016)
- 10/16 문서 마감·검사: [Docs/07](Docs/07_개발일지.md#web-1-2-20261016)
- 표지·실행 배경: [Docs/06](Docs/06_에셋_파이프라인.md#itch-art-20261015)

브라우저 저장은 Windows 저장과 별도입니다. 기존 Windows 1.1 빌드는 유지합니다.
