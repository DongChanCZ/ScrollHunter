# ScrollHunter
게임 ScrollHunter를 Git으로 관리하는 Repository 입니다.

## Web 빌드

현재 Web_Build 브랜치는 itch.io용 PC 브라우저 빌드입니다. 옵션에서 한국어/English를 고릅니다. 기존 영문 타이틀·클리어 문구는 유지합니다.

- 빌드: Unity 메뉴 Tools > Scroll Hunter > Build Web 1.1
- 출력: 바탕화면 ScrollHunter_Web_1.1
- 업로드·실행: [Docs/09](Docs/09_프로토타입_제작절차.md#web-language-20261014)
- 변경·검사: [Docs/07](Docs/07_개발일지.md#web-language-20261014)

브라우저 저장은 Windows 저장과 별도입니다. 기존 Windows 1.1 빌드는 유지합니다.
