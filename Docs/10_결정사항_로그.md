### A18. 채널링 정의와 구현 범위 (2026-09-21)

**사용자 확정:** 채널링은 시전하는 동안 효과가 유지되거나 발생하는 발동 방식이다. 채널링 중 다른 스킬은 발동할 수 없다. 2026-09-21에는 공통 기반만 구현했다. 아래 카드별 판정 중 시작 덱의 현재 구현 범위는 A20·07 D-08 참조. 나머지 카드 판정은 구현 완료 기록이 아니다.

| 구분 | 일반 시전 (`Cast`, 기존 카드 기본값) | 채널링 (`Channeling`) |
|---|---|---|
| 효과 시점 | 시전 완료 시 1회. 0초이면 입력 수락 시 즉시 | 입력 수락 시 시작, 진행 중 유지/발생, 종료 시 유지 효과 정리 |
| 시간 필드 | `castTime` = 효과 적용까지의 시간 | `castTime` = 채널링 지속시간. 유한한 양수 필요 |
| 다른 카드 사용 | MAX(시전시간, 최소 GCD) 동안 불가 | MAX(채널링 시간, 최소 GCD) 동안 불가. 입력 버퍼 없음 |
| 코스트·순환 | 입력 수락 시 1회 | 입력 수락 시 1회. 진행·종료 시 재소모·추가 순환 없음 |
| 효과 연결 | 기존 공격·차단·방어 처리 | `ChannelEffect`의 시작·진행·종료 기능. 일반 시전 효과를 종료 때 덧붙이지 않음 |

**기존 규칙을 따르는 기본 처리와 구현 조건:**

- 공격·차단·방어는 효과 분류, 단일·광역·자신은 대상 구분이다. 채널링은 그와 별개의 발동 방식이며 새 효과 분류가 아니다.
- 스스로 취소할 수 없고, 기절을 받으면 종료한다. 코스트 반환·추가 카드 순환은 없다. 기절이 행동 잠금을 대체한다. **무적·상태이상 면역·기절 무시는 채널링 자체에 포함되지 않으며 별도 스킬 사양·구현이 필요하다.**
- **전투 종료·재시작 시 모든 채널링을 즉시 종료.** 예정된 타격은 취소하고, 채널링 동안만 유지하는 효과는 해제. 이미 준 피해는 되돌리지 않음. 종료 자체로 코스트 반환·추가 순환 없음. 새 전투의 자원·덱 초기화는 별도 규칙을 따름.
- 정상 완료·기절·덱 초기화·컴포넌트 비활성화 때도 유지 효과 정리. 효과 코드 오류는 종료·정리를 시도하고 콘솔에 기록. 개별 효과의 `End`가 자신이 부여한 유지 상태를 해제해야 함.
- 일시정지는 종료가 아니다. 남은 시간과 진행 효과 호출을 멈추고 재개하면 이어진다. 진행 시간은 `Time.deltaTime`을 사용한다. 2배속 UI 구현 완료를 뜻하지 않는다.
- 효과 호출은 `Begin(context)` 1회 → `Tick(context, deltaTime)` 진행 중 → `End(context, reason)` 종료 시 1회다. 마지막 진행 시간은 남은 시간까지만 전달한다.
- `Tick`은 프레임 진행 시간 전달이며, 피해 횟수나 피해 간격을 뜻하지 않는다. 지속 피해 간격·첫 타격 시점·타겟 유지/전환 정책·수치 계산·유지 상태의 중첩/해제 방식은 개별 효과에서 정의한다. 효과 에셋은 사용마다 복제해 실행 상태를 공유하지 않는다.
- 시간이나 효과 연결이 유효하지 않으면 입력을 거절하며 코스트·카드를 소모하지 않는다. 기본 스킬 사용 횟수는 입력 수락 1회만 센다. 상세 틱 피해 등 추가 계측은 개별 효과 제작 시 연결한다.
- 기존 시전 바와 정보창은 채널링 이름·시간·설명을 표시. 공통 기반 구현 당시에는 개별 카드·무적·면역이 포함되지 않았음. 이후 시작 덱 채널링 2종을 구현했으며 A20 참조. 무적·면역은 미구현.

구현 연결·검사 실행 방법은 [09](09_프로토타입_제작절차.md#channeling-authoring), 구현 확인과 한계는 [07 D-07](07_개발일지.md#d07-channeling)에 둔다.

### A19. 적 피해·차단 표시 (2026-09-22 사용자 요청)

- 확정된 적 피해가 발생할 때 피해를 받은 적 위에 숫자 표시. NEXON Maplestory Bold 사용. X는 적 중심의 작은 범위에서 매번 무작위 결정. 생성 후에는 X를 유지하며 상승. 연출용 난수는 전투 난수와 분리.
- 일반 피해는 노랑, 치명타는 연한 빨강. 검정 테두리. 위로 올라가며 서서히 사라짐.
- 차단 성공 시 해당 적 위에 **「차단!」** 표시. 같은 폰트, 숫자보다 큰 보라색 글씨와 검정 테두리. X 무작위 생성·상승·페이드·정지·정리는 피해 숫자와 동일. 입력 시점이 아닌 효과 적용 후 성공 판정 시 표시하며 빨강·비캐스팅·시전 중 대상 공격이 먼저 끝난 경우에는 표시 없음.
- 숫자는 방어력 적용 후 피해값이며 과잉 피해를 포함. 실제 HP 감소량과 구분. 기존 합산형 에셋은 합산 피해 1개로 표시. 새 시작 덱의 타격별 판정·표시는 A20 참조.
- 광역은 맞은 적마다 표시. 피해 0·거절된 피해에는 표시 없음. 적이 죽어도 마지막 숫자는 유지.
- 정보 확인 정지 시 연출도 정지. 전투 종료 시 남은 숫자는 사라질 때까지 재생. 다음 전투·재시작에는 즉시 정리.
- 치명타 표시는 전달된 판정값을 사용. **현재 카드 공격에는 치명타 추첨이 없으며 이번 작업도 추첨·배율을 추가하지 않음.** 플레이어 피격 숫자는 이번 범위에 포함하지 않음.

### A22. 전투 가독성·0.5배속 (2026-09-22 사용자 관찰 반영)

- **배속 버튼:** 화면 상단 「속도」 좌클릭으로 1배속↔0.5배속 전환. 새 Play는 1배속, 현재 실행의 다음 전투·재시작에는 선택한 배속 유지. 일시정지 중 바꾸면 정지는 유지하고 재개할 배속만 바뀜. 승패 결과에서는 전환·재개 불가.
- **시간 기준:** 코스트 회복·시전/채널링·행동 잠금·기절·적 행동은 같은 게임 시간을 사용. 게임 내 회복량 0.8/초는 유지하므로 0.5배속의 현실 1초당 회복량은 0.4, 1코스트에 현실 2.5초. 요약 시간은 게임 초이며 시작·변경 배속의 게임 시각을 요약에 기록. A7의 2배속은 이번에 구현하지 않음.
- **코스트 부족 표시:** 각 카드의 `현재 코스트 / 카드 코스트`만큼 **12시에서 시작해 시계방향으로** 어두운 영역이 걷힘. 충전 완료 시 덮개 제거, 부족한 코스트 숫자는 빨강. 글자·유형 배지는 덮지 않으며 덮개가 클릭을 막지 않음. 카드 교체 즉시 새 코스트 기준으로 표시. 충전 완료가 다른 사용 조건 충족을 뜻하지 않음.
- **표시 우선순위:** 행동 잠금·기절·차단 대상 없음·설정 오류는 기존 상태 표시 우선. 그 상태에서는 충전 덮개를 숨김. 정지 중에는 현재 충전 상태 유지.
- **기절 시간:** 카드 하단 숫자는 숨김. 보라색 슬롯 음영과 화면 중앙 `기절 X.X`는 유지. 회색 행동 잠금의 카드별 남은 시간은 계속 표시.
- **공격 유형:** 기존 파랑 공격 배지의 이름을 `단일 / 광역`으로 나눔. `SkillData.IsAreaOfEffect`를 읽으며 카드 순환 즉시 갱신. 방어·차단 배지는 유지. 향후 아이콘이 들어가도 이 짧은 글자 표기를 보조 식별로 사용할 수 있음.
- 적 HP 임시 시험·카드 수치·덱·피해 판정은 변경하지 않음. 새 UI·0.5배속의 실측은 이전 기록과 별도 비교.

구현·관측은 [07 D-08](07_개발일지.md#d08-combat-readability), 실행은 [09](09_프로토타입_제작절차.md#combat-readability-checks) 참조.

### A23. 시연 보상·덱 교체 (2026-09-22 사용자 요청)

- **진행:** B→C→B+C의 1·2전투 승리 후 보상 선택 → 덱 교체 또는 스킵 → 편성 확인 → 다음 전투. 보상을 처리하기 전에는 다음 전투로 갈 수 없음. 3전투 승리·패배는 기존 결과·재시작 화면 사용.
- **시연 보상 풀:** 아래 카드 3종을 등록 순서대로 제시. 무작위 추첨·교육 곡선 보정은 이번에 적용하지 않음. 덱 내 같은 카드 중복 금지. 첫 보상에서 1종을 받으면 다음 보상에는 남은 2종만 제시. 스킵했다면 3종 유지. 후보가 없어도 스킵 후 진행 가능.
- **교체:** 보상 카드를 고른 뒤 현재 편성 8장 중 1장을 선택. 그 위치에 새 카드를 넣고 나머지 순서·장수 유지. 교체 전에는 보상 재선택·스킵 가능, 교체 확정 뒤에는 중복 획득·추가 교체 불가. 뺀 카드·스킵한 카드는 보관하지 않음(B8). 드래그 순서 변경·인벤토리는 이번 범위 아님.
- **이월:** 다음 전투는 현재 런의 편성 순서로 손패·대기열을 새로 시작. 전투 중 순환 위치는 이월하지 않음. 재시작은 A20의 저장 시작 덱·최대 HP로 복원. HP 이월·코스트 초기화 등은 아래 3전투 진행 절 유지.

### 3전투 진행·배치 (2026-09-21 사용자 요청 반영)

- **구성·전환:** B 단독 → C 단독 → B+C. 1·2전투 승리 후 A23의 보상·편성 확인을 마치고 「다음 전투」로 진행한다. 세 번째 승리는 완료 결과, 어느 전투에서든 패배하면 패배 결과를 표시하고 「처음부터 다시 시작」으로 첫 전투를 연다. 전투 번호는 화면과 전투별 계측 요약에 표시한다.
- **이월·초기화:** 다음 전투에 현재 HP와 런 편성을 이월하며 HP를 자동 회복하지 않는다. 코스트는 설정된 전투 시작값으로 되돌리고, 방어도·기절·행동 잠금·진행 중 효과·정보 확인 정지 상태는 초기화한다. 매 전투 현재 런 편성으로 손패·대기열을 다시 시작한다(A23). 적 HP·패턴·캐스팅·발동 간격과 전투별 시간·사용 순서·집계도 초기화한다. 재시작은 첫 전투·최대 HP·시작 덱으로 돌아간다. 종료 후 추가 카드 사용·피해는 막는다.
- **적 배치:** 전투 시작 시 1체는 중앙, 2체는 좌우, 3체는 가장 강한 적을 중앙에 둔다. **현재 A·B·C 구성은 사용자 선택으로 C가 중앙(A–C–B)**이다. 구현에서는 전투 구성의 `Center Enemy`로 강적을 명시하며 새로운 적의 강약을 공격 색이나 HP로 자동 확정하지 않는다. 나머지 적은 등록 순서대로 좌우에 배치한다. 체력바·캐스팅바·타겟 표시는 적을 따라가고, 타겟 이동 순서는 실제 좌→우다. 이번 구현은 시작 배치를 적용하며 전투 도중 사망 시 생존 적 위치를 바꾸지 않는다.
- **현재 범위:** 동일 Battle 씬을 재사용한다. 2026-09-21에는 진행 구조만 구현했고 이후 보상·덱 교체를 A23에 따라 연결했다. 별도 시작 화면·정식 5전투 런·계승은 미구현. 적 HP 임시값의 정식 채택 여부는 유지한다.

실행·구성 방법은 [09](09_프로토타입_제작절차.md#three-battle-checks), 실제 확인과 한계는 [07 D-07](07_개발일지.md#d07-three-battle-flow)에서 관리한다. 3체 배치 검사는 C를 중앙 적으로 지정해 확인했으며, 새로운 적 구성의 강약 순위까지 정한 것은 아니다.

위 표는 방어력0·치명타 없음·모든 대상 생존 및 과잉 피해 무시 조건의 산술값이다. 광역 시험안은 2체부터 현재 불기둥보다 총피해가 높지만 특정 1체를 깎는 피해는 78→60으로 줄고, 대응할 수 없는 시전시간은 1.2→2초로 늘어난다. 시전 중 기절하면 효과가 취소되는 기존 규칙을 유지한다. 실제 처치·HP 보존이 좋아지는지는 미확인이다.

**기존 정식 규칙과의 차이(사용자가 선택한 시험안에 한정한 예외. 시험용 에셋에만 적용되며 정식 규칙은 그대로):**

- `10` T11의 같은 코스트·2체 동등 규칙을 현재 단일 불기둥78에 적용하면 광역 대상당39가 된다. 시험값60은 이보다 높으며, 2체 합계120은78과 동등하지 않다. 사용자가 이 시험값을 선택했지만 2체 동등 규칙을 만족하는 값은 아니다.
- `10` T12의 광역 시전0.8~1.2초 범위에 시험값2초는 들어가지 않는다. 사용자가 피해는 제안과 같게 두고 시전2초를 선택했으므로 해당 시험에 한정한 예외로 기록한다.
- 시험안 승인과 정식 밸런스 채택은 별개다. 원본 T11·T12는 유지한다. 실제 구현은 2026-09-21 사용자 요청으로 시험용 에셋 1개에 한정해 진행했고, 정식 채택은 여전히 미결정이다.

복구 대상은 시험 직전의 임시 순환 덱이다. 광역 시험 카드만 대조용 단일 불기둥으로 교체하며 정식 원복값으로 자동 복구하지 않는다. 절차는 [09 광역 시험](09_프로토타입_제작절차.md#aoe-trial-procedure)을 따른다.
