### 0.1 용어 정의 (최우선) ★

| 용어 | 정의 |
|---|---|
| **런 (Run)** | 시작부터 사망 또는 최종 클리어까지의 한 회차 |
| **스테이지 / 전투** | 적 1~3체와의 교전 1회. **두 용어는 같은 의미** |
| **덱** | 전투에 들고 가는 8장. 순서 있음 |
| **손패** | 덱 앞 4장. QWER 슬롯. 위치 고정 |
| **대기열** | 덱 뒤 4장 |
| **순환** | 사용한 카드가 덱 맨 아래로 이동 (결정론적) |
| **행동 잠금 (GCD)** | 카드 사용 후 다음 카드를 못 쓰는 시간 = MAX(캐스팅, 최소 GCD) |
| **계승** | 런 종료 시 다음 런으로 넘기는 카드 또는 패시브 |
| **난이도 등급** | 플레이어가 런 시작 시 선택하는 적 강화 단계 |

> **1차 프로젝트(Soul Wanderer)에서는 "스테이지"가 지역(숲/바다/왕국)을 뜻했습니다.**
> 이번 프로젝트에서는 전투 1회를 의미하며, 1차 문서의 용법을 계승하지 않습니다.

### 0.2 플레이타임 계산

| 항목 | 20일 범위 | 출시 목표 |
|---|---|---|
| 잡몹 전투 | 4회 × 45초 = 3분 | 6~7회 × 45초 = 5분 |
| 보스 | 1회 × 180초 = 3분 | 3분 |
| 보상·덱 리빌딩 | 4회 × 60초 = 4분 | 7회 × 60초 = 7분 |
| **합계** | **약 10분** | **약 15분** |

> 20일 범위는 10분 내외입니다. 15~20분을 채우려면 잡몹 전투를 2~3회 늘려야 하는데,
> 적 종류를 늘리지 않고 조합만 바꾸면 비용이 크지 않습니다. **16~17일차에 여유가 있으면 추가하세요.**

### B10 상한의 UI 표현

패시브 상한을 플레이어에게 알리는 방법입니다. **별도 UI를 만들 필요가 없습니다.**

| 위치 | 표현 |
|---|---|
| **보상 화면** | 상한 도달 시 **해당 패시브를 추첨 풀에서 자동 제외.** 애초에 안 보이므로 설명이 불필요 |
| **패시브 목록** | 스택 수를 `(3/4)`로 표기. 상한 도달 시 `(4/4 MAX)` |
| **전투 화면** | 코스트 게이지 옆에 현재 회복 속도를 작게 표시 (`0.8/s`) |

> **핵심은 보상 풀에서 빼는 것입니다.** 회색 처리해서 보여주면 "왜 못 고르지"라는 의문이 생기지만, 아예 안 나오면 아무도 신경 쓰지 않습니다.
> 상한이 있는 패시브는 코스트 회복 하나뿐이므로, 이 처리만으로 충분합니다.

### D1 난이도 등급 설계

클리어할 때마다 자동으로 올라가는 방식이 아니라, **플레이어가 선택**합니다.

| 등급 | 적 피해·체력 | 해금 조건 |
|---|---|---|
| 0 | 100% | 기본 |
| 1 | 110% | 등급 0 클리어 |
| 2 | 121% | 등급 1 클리어 |
| 3 | 133% | 등급 2 클리어 |
| … | 이전 등급 × 1.1 | 이전 등급 클리어 |
| 상한 | **등급 7 (약 195%)** | — |

**계승으로 강해진 만큼 플레이어가 스스로 난이도를 올립니다.** 자동 증가 방식은 "실력이 늘지 않았는데 게임만 어려워지는" 문제가 있지만, 선택제는 그게 없습니다. 쉽게 하고 싶으면 등급 0으로 계속 할 수 있고, 도전하고 싶으면 올리면 됩니다.

시작 화면에 현재 해금된 최고 등급과 선택 UI를 두고, 계승 목록과 나란히 배치하세요.
