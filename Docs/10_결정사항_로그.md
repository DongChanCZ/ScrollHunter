### A18. 채널링 정의와 구현 범위 (2026-09-21)

**사용자 확정:** 채널링은 시전하는 동안 효과가 유지되거나 발생하는 발동 방식이다. 채널링 중 다른 스킬은 발동할 수 없다. 2026-09-21에는 공통 기반만 구현했다. 아래 카드별 판정 중 시작 덱의 현재 구현 범위는 A20·07 D-08 참조. 나머지 카드 판정은 구현 완료 기록이 아니다.

| 구분 | 일반 시전 (`Cast`, 기존 카드 기본값) | 채널링 (`Channeling`) |
|---|---|---|
| 효과 시점 | 시전 완료 시 1회. 0초이면 입력 수락 시 즉시 | 입력 수락 시 시작, 진행 중 유지/발생, 종료 시 유지 효과 정리 |
| 시간 필드 | `castTime` = 효과 적용까지의 시간 | `castTime` = 채널링 지속시간. 유한한 양수 필요 |
| 다른 카드 사용 | MAX(시전시간, 최소 GCD) 동안 불가 | MAX(채널링 시간, 최소 GCD) 동안 불가. 입력 버퍼 없음 |
| 코스트·순환 | 입력 수락 시 1회 | 입력 수락 시 1회. 진행·종료 시 재소모·추가 순환 없음 |
| 효과 연결 | 기존 공격·차단·방어 처리 | `ChannelEffect`의 시작·진행·종료 기능. 일반 시전 효과를 종료 때 덧붙이지 않음 |

**기존 규칙을 따르는 기본 처리와 구현 조건:**

- 공격·차단·방어는 효과 분류, 단일·광역·자신은 대상 구분이다. 채널링은 그와 별개의 발동 방식이며 새 효과 분류가 아니다.
- 스스로 취소할 수 없고, 기절을 받으면 종료한다. 코스트 반환·추가 카드 순환은 없다. 기절이 행동 잠금을 대체한다. **무적·상태이상 면역·기절 무시는 채널링 자체에 포함되지 않으며 별도 스킬 사양·구현이 필요하다.**
- **전투 종료·재시작 시 모든 채널링을 즉시 종료.** 예정된 타격은 취소하고, 채널링 동안만 유지하는 효과는 해제. 이미 준 피해는 되돌리지 않음. 종료 자체로 코스트 반환·추가 순환 없음. 새 전투의 자원·덱 초기화는 별도 규칙을 따름.
- 정상 완료·기절·덱 초기화·컴포넌트 비활성화 때도 유지 효과 정리. 효과 코드 오류는 종료·정리를 시도하고 콘솔에 기록. 개별 효과의 `End`가 자신이 부여한 유지 상태를 해제해야 함.
- 일시정지는 종료가 아니다. 남은 시간과 진행 효과 호출을 멈추고 재개하면 이어진다. 진행 시간은 `Time.deltaTime`을 사용한다. 2배속 UI 구현 완료를 뜻하지 않는다.
- 효과 호출은 `Begin(context)` 1회 → `Tick(context, deltaTime)` 진행 중 → `End(context, reason)` 종료 시 1회다. 마지막 진행 시간은 남은 시간까지만 전달한다.
- `Tick`은 프레임 진행 시간 전달이며, 피해 횟수나 피해 간격을 뜻하지 않는다. 지속 피해 간격·첫 타격 시점·타겟 유지/전환 정책·수치 계산·유지 상태의 중첩/해제 방식은 개별 효과에서 정의한다. 효과 에셋은 사용마다 복제해 실행 상태를 공유하지 않는다.
- 시간이나 효과 연결이 유효하지 않으면 입력을 거절하며 코스트·카드를 소모하지 않는다. 기본 스킬 사용 횟수는 입력 수락 1회만 센다. 상세 틱 피해 등 추가 계측은 개별 효과 제작 시 연결한다.
- 기존 시전 바와 정보창은 채널링 이름·시간·설명을 표시. 공통 기반 구현 당시에는 개별 카드·무적·면역이 포함되지 않았음. 이후 시작 덱 채널링 2종을 구현했으며 A20 참조. 생츄어리의 무적·기절 면역은 후속 A29 참조.

구현 연결·검사 실행 방법은 [09](09_프로토타입_제작절차.md#channeling-authoring), 구현 확인과 한계는 [07 D-07](07_개발일지.md#d07-channeling)에 둔다.

### A19. 적 피해·차단 표시 (2026-09-22 사용자 요청)

- 확정된 적 피해가 발생할 때 피해를 받은 적 위에 숫자 표시. NEXON Maplestory Bold 사용. X는 적 중심의 작은 범위에서 매번 무작위 결정. 생성 후에는 X를 유지하며 상승. 연출용 난수는 전투 난수와 분리.
- 일반 피해는 노랑, 치명타는 연한 빨강. 검정 테두리. 위로 올라가며 서서히 사라짐.
- 차단 성공 시 해당 적 위에 **「차단!」** 표시. 같은 폰트, 숫자보다 큰 보라색 글씨와 검정 테두리. X 무작위 생성·상승·페이드·정지·정리는 피해 숫자와 동일. 입력 시점이 아닌 효과 적용 후 성공 판정 시 표시하며 빨강·비캐스팅·시전 중 대상 공격이 먼저 끝난 경우에는 표시 없음.
- 숫자는 방어력 적용 후 피해값이며 과잉 피해를 포함. 실제 HP 감소량과 구분. 현재는 기존 에셋도 타격별 계산·표시. A25 참조.

### A22. 전투 가독성·0.5배속 (2026-09-22 사용자 관찰 반영)

- **현재 간이 UI:** 코스트는 하단 좌측 숫자·카드별 충전 음영, 다음 카드는 이름만 표시. 비캐스팅 대상의 차단 카드는 청회색·「잠김」. 실패음·슬롯 흔들림은 미구현.
- 코스트는 전투 중 시전·기절에도 충전. 일시정지·시작·보상·결과 화면에서는 중단.

- **배속 버튼:** 화면 상단 「속도」 좌클릭으로 1배속↔0.5배속 전환. 새 Play는 1배속, 현재 실행의 다음 전투·재시작에는 선택한 배속 유지. 일시정지 중 바꾸면 정지는 유지하고 재개할 배속만 바뀜. 승패 결과에서는 전환·재개 불가.
- **시간 기준:** 코스트 회복·시전/채널링·행동 잠금·기절·적 행동은 같은 게임 시간을 사용. 게임 내 회복량 0.8/초는 유지하므로 0.5배속의 현실 1초당 회복량은 0.4, 1코스트에 현실 2.5초. 요약 시간은 게임 초이며 시작·변경 배속의 게임 시각을 요약에 기록. A7의 2배속은 이번에 구현하지 않음.
- **코스트 부족 표시:** 각 카드의 `현재 코스트 / 카드 코스트`만큼 **12시에서 시작해 시계방향으로** 어두운 영역이 걷힘. 충전 완료 시 덮개 제거, 부족한 코스트 숫자는 빨강. 글자·유형 배지는 덮지 않으며 덮개가 클릭을 막지 않음. 카드 교체 즉시 새 코스트 기준으로 표시. 충전 완료가 다른 사용 조건 충족을 뜻하지 않음.
- **표시 우선순위:** 행동 잠금·기절·차단 대상 없음·설정 오류는 기존 상태 표시 우선. 그 상태에서는 충전 덮개를 숨김. 정지 중에는 현재 충전 상태 유지.
- **기절 시간:** 카드 하단 숫자는 숨김. 보라색 슬롯 음영과 화면 중앙 `기절 X.X`는 유지. 회색 행동 잠금의 카드별 남은 시간은 계속 표시.
- **공격 유형:** 기존 파랑 공격 배지의 이름을 `단일 / 광역`으로 나눔. `SkillData.IsAreaOfEffect`를 읽으며 카드 순환 즉시 갱신. 방어·차단 배지는 유지. 향후 아이콘이 들어가도 이 짧은 글자 표기를 보조 식별로 사용할 수 있음.
- 적 HP 임시 시험·카드 수치·덱·피해 판정은 변경하지 않음. 새 UI·0.5배속의 실측은 이전 기록과 별도 비교.

구현·관측은 [07 D-08](07_개발일지.md#d08-combat-readability), 실행은 [09](09_프로토타입_제작절차.md#combat-readability-checks) 참조.

### A23. 시연 보상·덱 교체 (2026-09-22 사용자 요청)

- **진행:** B→C→B+C의 1·2전투 승리 후 보상 선택 → 덱 교체 또는 스킵 → 편성 확인 → 다음 전투. 보상을 처리하기 전에는 다음 전투로 갈 수 없음. 3전투 승리·패배는 기존 결과·재시작 화면 사용.
- **카드 풀:** 당시 아래 3종. 현재 6종은 A29 참조. 덱 내 같은 카드 중복 금지. 2026-09-22에는 등록 순서대로 최대 3종을 제시했다. 현재 후보 수·추첨·패시브 연결은 A26을 따른다.
- **교체:** 보상 카드를 고른 뒤 현재 편성 8장 중 1장을 선택. 그 위치에 새 카드를 넣고 나머지 순서·장수 유지. 교체 전에는 보상 재선택·스킵 가능, 교체 확정 뒤에는 중복 획득·추가 교체 불가. 뺀 카드·스킵한 카드는 보관하지 않음(B8). 후속 순서 편집은 A31 참조. 인벤토리는 미구현.

### A25. 크리티컬 (2026-09-23 사용자 요청·판정 단위 확정)

- 플레이어 기본 확률 **15%**, 피해 배율은 T21. **타격·적마다 따로 판정**한다. 일반 다단히트·채널링·광역과 제압의 피해에 공통 적용한다.
- 입력 시 미리 추첨하지 않는다. 실제 피해 적용 직전에 현재 확률로 추첨하며, 타격별 배율·방어력 적용 후 한 번 반올림한다(T14·T19). 총 피해는 각 타격의 정수 피해 합이다.

- 일반 다단히트의 사망 뒤 잔여 숫자는 기존처럼 실피해 0인 연출이다. 일반 피해값·일반색으로 표시하고 새 추첨·유효 타격·치명타 횟수에서 제외한다. 사망시킨 타격은 집계한다.
- 치명타 숫자는 기존 A19의 연한 빨강·검정 테두리·상승/소멸을 사용. 일반 피해는 노랑 유지. 타격 로그에 치명타를 표시하고 전투 요약에 치명타 횟수/유효 피해 타격 횟수를 기록한다. 요약 마지막 출력은 A21 유지.
- Battle 씬 Player의 확률(%)·배율을 인스펙터에 저장. 카드 피해·타수·코스트·시전, 적 HP 시험값은 유지. 보존된 구 공격 에셋을 다시 사용할 때도 이제 타격별 계산을 따른다.
- 이 크리티컬 구현 당시 패시브는 별도 검토 대상이었다. 후속 PS09는 A26, PS01~10·포션은 A28 참조. 크리티컬이 없던 기존 플레이 계측과 새 계측을 같은 조건으로 합치지 않는다.

- **새 스킬 연출 추가 규칙:** `Systems`의 `SkillVfx` → Entries에 스킬과 프리팹을 연결한다(스킬당 1항목, 중복 시 첫 항목만 사용). `Impact At Target`(타격 시)과 `Impact Variants`(지정 시 타격마다 무작위 1개, 직전과 같은 것 제외, 연출 전용 난수)는 잔여 정리·막타 보류가 자동 적용, `Cast Zone`(시전·채널링 동안 적 1~3번 자리 구역 전체)·`Cast At Target`(시전 중)·`Self Effect`(방어 시 화면)·`Interrupt Success At Target`(차단 성공 시 대상, 실패 시 없음)는 정리만 자동이며 보류를 일으키지 않는다. 채널링 타격도 같은 알림이라 동일하게 동작.
  - `Channel Hit Lead Time`은 단일 피해 채널링의 비행 선행 시간. 아이스애로우만 0.1초, 나머지는 0(타격 시 생성). 프리팹의 비행 길이와 맞춘다.
  - `Impact Once Per Target`: 한 번에 여러 타가 동시에 들어가는 광역(현재 블리자드)은 켜서 대상마다 타격 연출을 1개만 생성. 같은 사용의 나머지 타격은 새로 띄우지 않고, 그 타격으로 쓰러지면 이미 띄운 연출을 막타로 이어 보류 판정에 쓴다. 매직 커터처럼 동시 2타를 X자로 겹쳐 보여주는 스킬은 끈다.
  - 타격 이펙트는 ParticleSystem으로 만든다. 보류 중 실제 시간 재생은 ParticleSystem에만 적용되며, Animator·자체 스크립트 부분은 보류 중 멈췄다가 정리된다.
  - SkillVfx를 거치지 않고 직접 생성한 연출은 정리·보류 대상이 아니다(예: 생츄어리 테두리는 CombatUI가 무적 상태로 켜고 끔).
  - 2초보다 긴 타격 이펙트는 `SkillVfx.impactLifetime`을, 긴 막타 연출은 `BattleFlow.finishingEffectHold`를 함께 검토한다(둘 다 전 스킬 공통값).
- 제압의 피해 숫자·차단 문구 일부 겹침은 사용자 판단으로 현행 유지(2026-09-29). 표시 간격·크기는 변경하지 않음.
- 보류 목록의 파티클·애니메이션에 대한 사용자 요청 예외. 2026-09-29 기준 현재 구현 스킬 14종 모두 전용 연출 연결(생츄어리는 UI 연출). 사운드는 미구현. 제작 이력은 [07](07_개발일지.md#d10-skill-vfx), 최종 검토·미확인은 [07](07_개발일지.md#d10-vfx-final-20260929), 재확인은 [09](09_프로토타입_제작절차.md#skill-vfx-checks).

### A31. 덱 순서 편집·시작 편성 (2026-09-29 사용자 요청)

- 「게임 시작」 → 튜토리얼 → 시작 덱 8장 확인 → 「전투 시작」. 첫 편성은 A32의 7단계 또는 스킵 후 진행한다(9/30 구현). 편성 화면에서는 전투·계측을 시작하지 않는다.

- 편집은 임시 순서에만 반영. 「저장」은 현재 런 편성에 적용하고, 「취소」는 편집 전 순서로 복귀. 이미 받은 카드·패시브는 취소하지 않는다. 후보 재추첨·추가 획득 없음.
- 편집 버튼은 왼쪽 「저장」, 오른쪽 「취소」로 배치.
- 편집 중에는 전투 진입 불가. 저장·취소 후 「전투 시작」 또는 「다음 전투」로 진행. 앞 4장은 QWER, 뒤 4장은 대기열이며 슬롯의 카드·정보도 함께 갱신.
- 덱은 보유한 8장 유지. 전투 중 편집·카드 추가/삭제 불가. 저장 순서는 다음 전투에도 이월한다. HP·포션·패시브 이월과 전투별 초기화는 기존 규칙 유지.
- 저장은 현재 런에만 적용. 기본 시작 덱·파일 저장·계승은 변경하지 않는다. 결과 화면의 「처음부터 다시 시작」은 기존처럼 기본 덱으로 첫 전투에 바로 진입.

#### 튜토리얼 학습·예외 규칙 (2026-09-29 확정, 9/30 후속 반영)

- **시작 편성:** 튜토리얼 전에는 순서를 편집하지 않는다. A20의 기본 덱·순서로 시작하며, 첫 편성 안내·편집은 적 처치 후 7단계에서 진행한다. 카드 사용에 따른 순환은 유지.
- **학습 잠금:** 5단계의 매직아머 입력 수락 전까지 현재 학습에 필요한 스킬만 허용. 설명 중·다음 학습 대기 중에는 전부 막고, 3단계 Q 파이어볼·4단계 E 침묵·5단계 R 매직아머 입력을 각각 한 번 허용한다. 나머지 슬롯은 음영 처리하고 키보드·좌클릭 모두 거절. 사용 후 같은 슬롯에 들어온 다음 카드도 잠근다.
- **안내 정지:** 설명을 표시하는 동안 게임 시간을 멈춘다. 안내 넘김은 엔터(숫자패드 포함)·스페이스바·좌클릭이며, 그 입력으로 밑의 카드까지 사용되지 않게 구분한다.
- **안내 표시(9/30):** 화면의 `학습 n/7`은 삭제. 안내창 우측 하단에는 `Space`만 표시하며 실제 입력은 위 세 방식 모두 허용한다. 지정 스킬 입력을 기다릴 때는 `Space` 표시를 숨기고 Q/E/R 안내를 유지한다.
- **스킬 학습 완료:** 3~5단계는 지정 스킬의 유효 입력 수락으로 완료한다. 입력 수락 시 안내 정지를 풀고 코스트 소모·카드 순환 후 기존 시전 시간에 따라 효과를 적용한다. 효과를 정지 중 즉시 적용하거나 차단 성공을 완료 조건으로 바꾸지 않는다. 거절된 입력은 학습을 넘기거나 정지를 풀지 않는다. 5단계 수락 후 학습 잠금은 전부 해제하되 일반 GCD·기절·코스트·대상 조건은 유지한다.
- **포션 학습:** 6단계 안내는 엔터·스페이스바·클릭으로만 닫는다. 안내 중 Shift는 사용·학습 완료·입력 예약 모두 불가. 안내 뒤 처치 안내까지 닫아 게임 시간이 흐를 때 기존 A28 조건으로 사용할 수 있다. 실제 포션 사용은 학습 완료 조건이 아니다. 일반 수동 정지의 카드·포션 사용 금지는 유지.
- **공격 순서 예외:** 튜토리얼만 초록→주황→빨강을 고정 반복하며 초록부터 시작한다. M항의 공격 선택 우선순위·초록 횟수 쿨다운 대신 이 순서를 사용한다. 차단된 공격도 해당 순서를 마친 것으로 보고 차단 경직 후 다음 공격으로 진행. 피해·색별 차단 가능 여부·경직·빨강 반감은 공통 규칙 유지.
- **처치 안내(9/30):** 포션 설명 뒤 적 HP가 남아 있으면 `이제 공격스킬을 써서 적을 처치하세요`를 표시한다. 안내 중 정지·입력 제한을 유지하고 엔터·스페이스바·좌클릭으로 닫으면 자유 전투 재개. 별도 학습 번호는 추가하지 않는다. 이미 적 HP가 0이면 이 안내는 생략한다.
- **종료 순서:** 전투 학습 1~6 완료와 적 HP 0을 모두 충족하면 처치 확정 → 완료 안내 → 확인 입력 → 편성 학습 7 → A+B 진입. 먼저 HP 0이 되면 처치·승리를 보류하고 전투 학습에 필요한 공격·대상 지정을 유지한다. 7단계를 적 처치의 선행 조건으로 사용하지 않는다. A+B 진입의 HP·포션 초기화는 위 규칙 유지.
- **강조 방식:** 강조할 부분을 제외한 화면을 어둡게 표시한다. 화면 확대는 사용하지 않는다. 비활성 슬롯 음영과 스킬창 위 안내창을 함께 사용한다.

### A33. 빨강 공격 — 방어도 보유 시 피해 반감 (2026-09-29 사용자 확정)

- 빨강 피격 직전 방어도가 1 이상이면 피해 50% 감소. 방어도 0이면 감소 없음. 방어력 스탯과 방어도는 별개다.
- 방어력 계산에 반감 배율을 곱한 뒤 T19로 한 번만 반올림. 이후 방어도 → HP 순서로 차감한다. 반감 조건만으로 방어도를 따로 소모하지 않는다.
- 판정은 매 타격 직전. 앞선 공격으로 방어도가 0이 됐다면 다음 빨강은 반감되지 않는다. 초록·주황은 기존 흡수만 적용. 빨강 차단 불가 유지.
- 생츄어리 무적 중에는 피해·방어도 소모 없음. 무효화 피해 계측은 기존 기준(방어력 적용 후·방어도 조건 반감 전)을 유지하고 반감·흡수와 중복 집계하지 않는다.
- **C 빨강은 플레이어 방어력 20·방어도 0에서 실피해 200. 원본 피해 240으로 변경한다.** 방어도가 있으면 흡수 전 피해 100. 사용자의 200은 실피해를 묻는 질문에 대한 답변 기준이다. 다른 적의 기본 피해·스킬 수치·피격 간격은 변경하지 않는다.

`빨강 피해 = 원본 피해 × 100 / (방어력 + 100) × (피격 직전 방어도 > 0 ? 0.5 : 1)`

| C 빨강 피격 직전 방어도 | 반감·반올림 후 피해 | 방어도 흡수 | HP 감소 | 남은 방어도 |
|---|---|---|---|---|
| 0 | 200 | 0 | 200 | 0 |
| 1 | 100 | 1 | 99 | 0 |
| 120 | 100 | 100 | 0 | 20 |

- 최초 설명의 250→125는 예시. 그 조건에서 방어도 1이면 1 흡수·HP 124 감소가 맞다. C의 채택값은 위 표를 따른다.
- 계측에서 반감으로 줄인 피해와 실제 방어도 흡수량을 구분한다. 방어도 1로 반감 후 1을 흡수했다면 흡수량은 1이다.
- **2026-09-29 Unity 구현·기능 검사 완료.** C 원본 피해·빨강 조건 반감·적 정보창·피격 로그·별도 감소량 집계를 연결했다. 검사 범위는 07 참조. 기존 실측·실행 파일은 당시 규칙의 결과로 보존하며, 새 빌드·사용자 플레이·밸런스시트 재계산은 미수행.

진행 기록은 [07 D-10](07_개발일지.md#d10-red-shield), 재확인은 [09](09_프로토타입_제작절차.md#red-shield-checks) 참조.

### A34. 보스 패턴·페이즈 (2026-09-30 확정·구현)

- 보스 **마법사 / HP 4000 / 방어력 0 / 시작 방어도 0**. 04 작성값으로 구현. 패턴 1~5 원본 피해는 **35 / 40 / 300 / 60 / 600**.
- 시전 시간은 04 패턴 정리 표를 기준으로 통일. 기본 시간은 패턴 1~5 순서로 2 / 3 / 6 / 5 / 20초.
- **시전 시간 -20%는 2페이즈에만 적용.** 3페이즈는 기본 시간으로 복귀. 표의 ‘감소 고려’ 메모는 기본값에 이미 감소를 적용했다는 뜻으로 사용하지 않는다.

| 페이즈 | HP 기준 | 반복 순서 | 시전 시간 |
|---|---|---|---|
| 1 | 시작~60% | 1→2→1→3 | 기본값 |
| 2 | 60% 이하~25% | 1→1→4→1→3→1→2 | 기본값 × 0.8 |
| 3 | 25% 이하 | 5→1→4→1→3→1 | 기본값 |

- 기존 전환 연출은 2초 유지. **전환 중 게임 시간은 흐르며 플레이어의 새 스킬 사용은 불가.** 코스트 충전은 계속된다. 거절된 입력은 코스트·카드를 소모하지 않는다.
- **보스 예외:** M항의 색 우선순위·초록 횟수 쿨다운 대신 위 순번대로 반복. 같은 색이어도 패턴 번호로 구별한다. **초록 차단은 현재 순번 유지, 경직 후 같은 초록을 처음부터 다시 시전한다. 주황 차단은 순번을 소모하고 경직 후 다음 순번으로 진행한다.** 초록도 실제 발동하면 다음 순번으로 진행. 전환 조건을 충족했다면 같은 초록 재시전보다 새 페이즈의 첫 패턴을 우선한다. 9/30 후속 사용자 승인·구현, 확인은 [07](07_개발일지.md#d11-boss-ready).
- 패턴 4 나이트메어는 기절 5초. 다른 주황의 기본 기절 2초와 구분한다. 초록·주황 차단 가능, 빨강 차단 불가·방어도 반감, 발동 후 경직·차단 경직은 공통 규칙 유지.
- **전환 시작:** HP 기준에 도달하면 진행 중인 보스 공격의 발동 또는 차단 후 전환. 1→2는 패턴 1, 2→3은 패턴 5부터 시작한다. HP가 한 번에 60% 위에서 25% 이하로 내려가면 2페이즈를 건너뛰고 3페이즈로 전환한다.
- 발동 후 쉬는 중이나 차단 경직 중 HP 기준에 도달하면, 공격이 이미 끝났으므로 바로 전환. 치명 피해는 전환보다 사망을 먼저 처리.
- **전환 중:** 보스만 무적. 플레이어의 진행 중 시전·채널링은 계속되며, 전환 중 보스에게 들어가는 피해는 무효.
- **전환 중 조작:** 포션·수동 정지 허용. 일반 수동 정지 중에는 기존 규칙대로 스킬·포션 사용 불가. 수동 정지하면 전환·경직·시전 시간도 멈춘다.
- **전환과 경직:** 동시에 진행하며 둘 다 끝나면 다음 공격 시작. 차단 경직 2.5초라면 다음 공격까지 2.5초이며 전환 2초를 더하지 않는다. 전환 2초가 끝나면 보스 무적·새 스킬 사용 금지는 해제하고, 남은 경직만 기다린다.

- **사용 피드백(10/1 사용자 추가):** 스킬·물약 입력 **수락** 때만 아이콘 수축·복귀·점등. 스킬은 기존 금속 테두리 점등, 물약은 짧은 초록빛 입자. 거절 입력에는 재생하지 않고, 입력 수락과 효과 성공(피해 숫자·「차단!」)을 구분한다. 카드가 즉시 순환하므로 사용한 카드 아이콘을 따로 띄워 새 카드와 혼동하지 않게 한다. 카드 순환·시전·GCD·입력 가능 시점은 바꾸지 않는다.
- **타겟 마커(10/1 사용자 추가):** 기존 UI에 맞는 청동 문양·밝은 아이보리 화살촉. HP 바 위 마커와 선택된 적 게이지(HP 바)의 얇은 강조선으로 식별. 타겟 변경 순간만 짧게 강조하고 캐스팅 정보를 가리지 않는다. 시전 중 수동 변경 제한·사망 시 자동 이동 규칙(target-lock) 유지.
- **버튼 외곽(10/1 사용자 요청, 공통 적용):** 좌우 둥근 끝 장식을 빼고 모서리만 짧게 사선으로 깎은 직사각형. 시작·전투 시작/다음 전투·재시작·순서 변경·저장·취소·보상 스킵·뒤로·정지·배속·능력치·튜토리얼 스킵에 적용. 기존 회색/청흑색 재질·금색 테두리·크기·글자 배치·클릭 영역·상태 구분 유지. 카드·설명 패널·시전 바 외곽은 유지.
- 낮은 HP의 약한 맥동·화면 가장자리 경고는 후속 후보. 기준·강도는 미정이며 이번 필수 적용에서 제외한다. 화면 전체 점멸·흔들림·히트스톱·새 사운드는 추가하지 않는다.
- **글꼴(10/1 후속):** 시작 화면 제목은 Cinzel Bold. 데미지·차단은 기존 NEXON Maplestory Bold, 기절·일반 UI는 Gmarket Sans 유지. Noto Serif KR Black 전투 표시는 사용자 요청으로 원복. 기존 색·외곽선·크기·상승·페이드 유지.
- 전체 UI 적용 범위: 시작·튜토리얼 안내·편성·전투 HUD·스킬/적 정보창·보상·결과. 기존 이름/설명 정렬, 스킬 프레임·아이콘·상태 표시를 유지하며 배경 판·장식·대비·여백을 맞춘다. 폰트는 위 후속 결정을 따른다.
- 전투 규칙·밸런스·보상 추첨·기존 14종 스킬 연출은 변경하지 않는다. Battle Chasers의 적·배경 방향은 유지하되 신규 3D 모델·배경 제작은 이번 UI 인계에 포함하지 않는다.

- 픽셀 크기·HEX·추가 에셋은 문서 정리 당시 미정이었고 10/1 적용값은 [07 D-12](07_개발일지.md#d12-ui-design), 추가 에셋은 CREDITS. 화면 기준은 [A27 후속](#display-mode-20261001). 전투 화면부터 조합하고 다른 UI 화면으로 확장한다. 적용 순서·검사는 [09](09_프로토타입_제작절차.md#visual-style-checks).

### A41. 적 공격 연출 기준 (2026-10-06)

사용자 요청으로 깡패·약탈자·궁병·우두머리에 공격 연출을 추가. 마법사는 제외. 피해·시전 시간·경직·차단 규칙·패턴, 공격 클립·재생 속도·타격 위치, 모델 크기·회전·시선, 무기 장착·손 보정, 플레이어 스킬 연출·UI는 유지한다.

| 적 | 연출 | 표시 구간 |
|---|---|---|
| 깡패 | 타격 빛·충격 고리·짧은 바람선. 잽 왼주먹 앞, 크로스 오른주먹 앞, 발차기 오른발 끝 | 실제 발동 때 1회 |
| 약탈자 | 단검 끝쪽의 청백 궤적(0.2초) | 회전 베기 클립 0.26~0.42 |
| 우두머리 | 칼날 끝쪽 금빛 궤적(약탈자보다 넓게, 0.15초) + 칼끝 빛·섬광·충격선 | 초록 올려베기 0.33~0.49, 빨강 내려베기 0.31~0.49. 섬광은 실제 발동 때 1회 |
| 궁병 | 활 손잡이 앞 빛·섬광·공기 고리·흐린 공기. 기존 발사 화살에 짧은 꼬리(0.09초) | 실제 발사 때 1회. 당김 중 없음 |

- **10/6 후속(사용자 요청):** 궤적을 더 굵고 진하게, 모든 효과를 더 진하게. 궤적 폭(키 1 기준) 약탈자 0.025→0.065·우두머리 0.07→0.11, 진하기 0.75/0.5→1/0.95, 꼬리 굵기·진하기 유지 구간 확대, 색 채도 상향(청백·금빛). 타격·발사 효과는 불투명도 최대·크기 약 1.3배·수명 약 1.2배, 궁병에 빛 1층 추가. 표시 구간·위치·판정·애니메이션 시간은 유지.

- 연결: `EnemyAttackVfx`가 `EnemyAnimationDriver`의 공격 진행과 실제 발동·취소 알림만 읽는다. 피해·차단 판정을 부르지 않으며 별도 실시간 대기·타이머가 없다. 궤적은 공격 동작 중이고 클립 위치가 위 구간일 때만 켠다.
- 동시 발동 간격 대기 중에는 타격 효과가 없고 실제 발동 때만 생성. 차단 성공·사망·편성 끄기·전투 전환·재시작은 궤적과 남은 효과를 지운다. 빨강 차단 실패는 공격이 그대로 진행한다. 파티클·궤적은 게임 시간이라 정지·0.5배속을 따른다. 궤적은 켤 때마다 비워 순간이동 줄을 남기지 않는다.
- 색은 흰색·청백·금빛만 사용해 공격 색(초록·주황·빨강)과 겹치지 않는다. 지속 발광·화면 전체 섬광 없음. 크기는 키 2 모델 기준이며 모델 크기에 비례한다.
- 위 구간·위치·크기는 전투 수치가 아닌 연출 조정값이다. 모션 교체 때 다시 맞춘다. 적용 메뉴 `Tools > Scroll Hunter > Apply Enemy Attack VFX`(적 빌더 재실행 없음). 빌더로 프리팹을 다시 만들면 이 메뉴도 다시 실행한다.
- 텍스처는 기존 Kenney Particle Pack(CC0)·자체 TrailSoft 재사용, 새 외부 에셋 없음([CREDITS](CREDITS.md)). 적용·검사·남은 문제 [07](07_개발일지.md#d14-enemy-attack-vfx), 절차 [09](09_프로토타입_제작절차.md#enemy-attack-vfx-checks).

### A42. 마법사 보스 공격 연출 기준 (2026-10-06)

사용자 요청으로 마법사 공격 5종에 시전·발동 연출을 추가. 현재 동작([mage-skill-motions](#mage-skill-motions-20261006)·[mage-charge-pose](#mage-charge-pose-20261006))·손 보정·모델 방향/크기·시전 시간·피해·패턴·차단 규칙, 플레이어·다른 적 연출은 유지한다. 연출을 동작에 맞추며 동작을 바꾸지 않는다.

| 스킬(공격 순서) | 준비 (시전당 1개, 진행률로 성장) | 실제 발동 (1회) |
|---|---|---|
| 매직미사일(파이어볼 연출) | 오른손 보라 불꽃: 짙은 보라 바탕·연보라/보라 중심·불티 | 손 앞 섬광 → 보라 불덩이(짧은 불꽃 꼬리)가 화면 아래 플레이어 쪽으로 0.22초 비행 → 보라 폭발 착탄. 이름·전투 데이터는 매직미사일 유지 |
| 사일런스 | 내민 오른손에 보라 구체·압축 고리·모이는 입자 | 손 앞 보라 섬광·이중 마력 고리·마력진 확산 |
| 다크홀 | 손을 든 동안 든 손에서 기운이 내려와 가슴 앞에 검은 구체(진홍/보라 테두리)·흡입 입자 | 구체 붕괴(검은 수축) → 진홍·보라 충격 고리·검은 연기·파편. 디엔드보다 작고 짧음 |
| 나이트메어 | 몸을 감도는 짙은 보라 연기·그림자·보라 잔상(흐르는 형태) | 옆으로 퍼지는 보라 연기 파동·그림자 줄기·소용돌이 |
| 디엔드 | 머리 위(게이지·마커 위 빈 공간)에 검은 큰 구체. 테두리·안쪽 소용돌이·붉은 불티, 바깥 기운·연기 흡입, 든 손→구체 기운 줄기. 시전 진행에 따라 0.25→1배 성장, 종료까지 유지 | 구체 수축 → 큰 충격 고리·검은 연기 폭발·파편 + 발밑 바닥 충격파 |

- 공격 구분: 보스는 같은 색 공격이 여럿이라 색이 아닌 공격 목록 순서로 고른다. `EnemyAnimationDriver`가 시전 시작 때 고른 번호(`MotionIndex`)와 표시용 알림 `AttackPrepared`를 낸다. 발동 순간 `CurrentAttack`을 읽지 않으며, 다른 적의 색 번호(`AttackIndex`)·`AttackImpact` 의미는 유지한다.
- 연결: `BossAttackVfx`(마법사 모델 루트)가 시전 시작에 준비 효과 1개를 만들고 매 프레임 실제 시전 진행률(2페이즈 배율 포함)로 크기·입자량만 갱신. 동시 발동 간격 대기에는 진행률 1로 유지, 실제 발동 알림 때 방출·폭발 1회. 피해·기절·차단 판정을 부르지 않고 별도 타이머가 없다.
- 차단 성공·사망·편성 끄기·재활성화는 준비 효과·투사체·남은 효과를 지운다(뒤늦은 방출 없음). 빨강 차단 실패는 그대로 진행. 파티클·성장·비행은 게임 시간이라 정지·0.5배속을 따른다.
- 크기·위치·색·입자량·비행 시간은 연출 조정값(전투 수치 아님)이며 `BossAttackVfx` Inspector(스킬별 준비/방출 배율·기준점·오프셋·성장 곡선)와 적용 메뉴 `Tools > Scroll Hunter > Apply Mage Attack VFX`에서 조정. 디엔드 구체 높이는 머리 뼈 위 2.7m(키 2 기준), 광범위 폭발은 시각 표현이며 피해 범위·횟수·수치는 그대로다.
- **10/6 후속(사용자 요청):** 매직미사일(파이어볼) 연출 색을 붉은 불꽃에서 보라 불꽃으로 변경. 형태·크기·비행·시점은 유지. 주황이 들어 있는 Explosion03 착탄 시트는 보라로 물들지 않아 Kenney 흰 텍스처의 섬광·불꽃·고리 폭발로 교체. 사일런스(보라 고리·마력진)와는 불꽃·불덩이 형태로 구분한다.
- 에셋은 기존 반입 Kenney Particle Pack(CC0)·자체 TrailSoft 재사용, 새 외부 에셋 없음([CREDITS](CREDITS.md)). 적용·검사·남은 문제 [07](07_개발일지.md#d14-mage-attack-vfx), 절차 [09](09_프로토타입_제작절차.md#mage-attack-vfx-checks).

<a id="passive-limits-20260923"></a>
### B14. PS별 상한·최대치 증가 (2026-09-23 사용자 확정)

- **상한은 각 PS에 따로 적용.** 해당 PS의 획득·중첩만 제한한다. 다른 PS가 올린 같은 능력치를 합쳐 상한을 판정하지 않는다.
- PS10의 효과는 다른 PS의 스택을 소모하지 않는다. 다른 PS가 상한이어도 PS10은 자신의 상한 전까지 획득 가능하다.
- 03 표의 최종값은 해당 PS만 적용한 값이다. 예: PS04 4스택으로 회복 속도 1.2/초가 된 뒤 PS10의 +0.1을 받으면 **1.3/초**가 된다. PS04는 여전히 4스택이다.
- **최대치 증가 자체는 현재값을 회복·보충하지 않는다.** 최대 HP 증가 시 현재 HP 유지. 예: HP `350/500 → 350/550`. 별도로 적힌 회복·지급 효과만 현재값을 늘린다.
- PS03·PS10은 현재 HP 유지. PS01은 최대치 증가와 별도로 포션 1개를 지급한다(A28). PS02는 즉시 HP 회복 효과다.
- PS01 획득 외 전투 간 자동 보충은 없다. 튜토리얼 종료 예외는 A32, 기본 포션·새 런 초기화는 A8·A28을 따른다.

이 규칙 확정 당시에는 전체 패시브·포션이 미구현이었다. 이후 사용자 승인으로 PS01~10·포션을 연결했고 PS10의 1% 추첨도 확정했다(A28).

### B9·B10 상한의 UI 표현

패시브 상한을 플레이어에게 알리는 방법입니다. **별도 UI를 만들 필요가 없습니다.**

| 위치 | 표현 |
|---|---|
| **보상 화면** | 상한 도달 시 **해당 패시브를 추첨 풀에서 자동 제외.** 애초에 안 보이므로 설명이 불필요 |
| **패시브 목록** | 스택 수를 `(3/4)`로 표기. 상한 도달 시 `(4/4 MAX)` |
| **전투 화면** | 현재 충전 속도·크리티컬 확률과 보유 스택을 하단에 표시(A26) |

> **핵심은 보상 풀에서 빼는 것입니다.** 회색 처리해서 보여주면 "왜 못 고르지"라는 의문이 생기지만, 아예 안 나오면 아무도 신경 쓰지 않습니다.
> 각 PS의 스택 상한을 기준으로 해당 PS만 제외한다. 같은 능력치를 올리는 다른 PS는 자신의 상한으로 판정한다(B14).

**시전 중 타겟 변경 제한 (2026-09-28 사용자 확정)**

- 일반 시전·채널링 중 클릭·방향키 입력은 무시. 예약하지 않는다. 일시정지 중에도 같다.
- 시전 종료·취소 후 다시 선택 가능. 즉발기나 시전 종료 후 남은 GCD만으로는 타겟 변경을 막지 않는다.
- 대상 사망 시 자동 이동은 유지. 일반 시전은 완료 시 생존한 현재 타겟에게 적용. SK02는 입력 대상을 유지하며 사망 시 기존 중단·후딜 규칙 적용.
- 확인 절차는 [09](09_프로토타입_제작절차.md#target-lock-checks), 구현·검사는 [07](07_개발일지.md#d10-target-lock).

> **T1 결정 근거:** 차단 전용 타겟 + Tab 순환 방식도 검토했으나, 조작에 필요한 정보가 늘어
> 학습 부담이 커진다고 판단해 기각. 타겟 개념을 하나로 유지하면 "분류를 보면 대상이 정해지는" 일관된 규칙이 된다.

> **T11 주의:** 광역기 코스트를 올리면 피해량도 비례해 올려야 손익분기가 유지됩니다.
> 단일 120 @ 코스트 3 ↔ 광역 120 @ 코스트 6 이 2체에서 동등합니다.

> **T19 근거:** `Mathf.RoundToInt`는 이름과 달리 은행가 반올림(round half to even)입니다.
> `0.5 → 0`, `2.5 → 2`로 .5에서 짝수에 붙습니다. `Math.Round` 기본값도 동일합니다.
> `FloorToInt(x + 0.5f)`는 항상 올림 방향으로 고정되어 설계자가 예상한 값과 일치합니다.
> 코드 세션에서 실측으로 확인된 사항입니다 (2026-09-15).

> **T18 근거:** `피해량 × (1 - 방어력/(방어력+100))` 형태는 나눗셈이 두 번 일어나
> 부동소수점 오차가 생깁니다. 30 → 24.999998이 되어 내림 시 24가 나오고, 04 문서의 실피해 25와 어긋납니다.
> 곱셈을 먼저 하면 `30 × 100 / 120 = 25`로 정확합니다.

> **T13 근거:** 카드에 적힌 숫자가 곧 피해량이라 플레이어가 직접 읽고 계산할 수 있습니다.

> 기존 스킬 8장은 **계수 × 100**으로 환산했으므로 밸런스 변화가 없습니다.

### D1 난이도 등급 설계

클리어할 때마다 자동으로 올라가는 방식이 아니라, **플레이어가 선택**합니다.

| 등급 | 적 피해·체력 | 해금 조건 |
|---|---|---|
| 0 | 100% | 기본 |
| 1 | 110% | 등급 0 클리어 |
| 2 | 121% | 등급 1 클리어 |
| 3 | 133% | 등급 2 클리어 |
| … | 이전 등급 × 1.1 | 이전 등급 클리어 |
| 상한 | **등급 7 (약 195%)** | — |

**계승으로 강해진 만큼 플레이어가 스스로 난이도를 올립니다.** 자동 증가 방식은 "실력이 늘지 않았는데 게임만 어려워지는" 문제가 있지만, 선택제는 그게 없습니다. 쉽게 하고 싶으면 등급 0으로 계속 할 수 있고, 도전하고 싶으면 올리면 됩니다.

시작 화면에 현재 해금된 최고 등급과 선택 UI를 두고, 계승 목록과 나란히 배치하세요.

## 2026-09-16 차단·손패 규칙 변경 반영

> **이 절이 이 변경의 원본이다.** `02`·`04`·`08`·`09` 는 각자의 변경 이력에서 여기를 가리킨다.
> `09` 에는 이 사양의 「새 사양 확인 순서」만 따로 둔다.

침묵은 코스트 **2**, 시전 **0.2초**, 차단 성공 경직 **2.5초**. 초록·주황은 차단 가능하고 빨강은 차단 불가. 입력 시 대상이 캐스팅 중이어야 사용 가능하며, 효과 적용 순간에도 초록·주황 캐스팅 중이어야 성공한다. 그전에 적 공격이 발동했으면 차단 실패이며 경직을 주지 않는다. 빨강 또는 시전 중 적 캐스팅 종료로 실패해도 코스트·카드는 소모된다.

유효한 입력을 수락하는 즉시 코스트를 소모하고, 사용 카드를 덱 맨 아래로 보낸 뒤 대기열 맨 앞 카드를 같은 손패 슬롯에 넣는다. 새 카드는 행동 잠금 중 사용할 수 없다. 일반 시전 효과는 완료 시 적용한다(2026-09-21 추가된 채널링은 A18 참조). 자발적 취소는 불가하며, 기절에 의한 강제 취소 시 효과만 취소하고 코스트 반환·추가 카드 순환은 하지 않는다. 비캐스팅 대상 차단 등 거절된 입력은 코스트·카드를 소모하지 않는다.

### 3전투 진행·배치 (2026-09-21 사용자 요청 반영)

- **구성·전환:** B 단독 → C 단독 → B+C. 1·2전투 승리 후 A23의 보상·편성 확인을 마치고 「다음 전투」로 진행한다. 세 번째 승리는 완료 결과, 어느 전투에서든 패배하면 패배 결과를 표시하고 「처음부터 다시 시작」으로 첫 전투를 연다. 전투 번호는 화면과 전투별 계측 요약에 표시한다.
- **이월·초기화:** 다음 전투에 현재 HP·런 편성·획득 패시브(A26)를 이월하며 HP를 자동 회복하지 않는다. 코스트는 설정된 전투 시작값으로 되돌리고, 방어도·기절·행동 잠금·진행 중 효과·정보 확인 정지 상태는 초기화한다. 매 전투 현재 런 편성으로 손패·대기열을 다시 시작한다(A23). 적 HP·패턴·캐스팅·발동 간격과 전투별 시간·사용 순서·집계도 초기화한다. 재시작은 첫 전투·최대 HP·시작 덱으로 돌아가고 획득 패시브를 초기화한다(A26). 종료 후 추가 카드 사용·피해는 막는다.
- **적 배치:** 전투 시작 시 1체는 중앙, 2체는 좌우, 3체는 가장 강한 적을 중앙에 둔다. **현재 A·B·C 구성은 사용자 선택으로 C가 중앙(A–C–B)**이다. 구현에서는 전투 구성의 `Center Enemy`로 강적을 명시하며 새로운 적의 강약을 공격 색이나 HP로 자동 확정하지 않는다. 나머지 적은 등록 순서대로 좌우에 배치한다. 체력바·캐스팅바·타겟 표시는 적을 따라가고, 타겟 이동 순서는 실제 좌→우다. 이번 구현은 시작 배치를 적용하며 전투 도중 사망 시 생존 적 위치를 바꾸지 않는다.

위 표는 방어력0·치명타 없음·모든 대상 생존 및 과잉 피해 무시 조건의 산술값이다. 광역 시험안은 2체부터 현재 불기둥보다 총피해가 높지만 특정 1체를 깎는 피해는 78→60으로 줄고, 대응할 수 없는 시전시간은 1.2→2초로 늘어난다. 시전 중 기절하면 효과가 취소되는 기존 규칙을 유지한다. 실제 처치·HP 보존이 좋아지는지는 미확인이다.

**기존 정식 규칙과의 차이(사용자가 선택한 시험안에 한정한 예외. 시험용 에셋에만 적용되며 정식 규칙은 그대로):**

- `10` T11의 같은 코스트·2체 동등 규칙을 현재 단일 불기둥78에 적용하면 광역 대상당39가 된다. 시험값60은 이보다 높으며, 2체 합계120은78과 동등하지 않다. 사용자가 이 시험값을 선택했지만 2체 동등 규칙을 만족하는 값은 아니다.
- `10` T12의 광역 시전0.8~1.2초 범위에 시험값2초는 들어가지 않는다. 사용자가 피해는 제안과 같게 두고 시전2초를 선택했으므로 해당 시험에 한정한 예외로 기록한다.
- 시험안 승인과 정식 밸런스 채택은 별개다. 원본 T11·T12는 유지한다. 실제 구현은 2026-09-21 사용자 요청으로 시험용 에셋 1개에 한정해 진행했고, 정식 채택은 여전히 미결정이다.

복구 대상은 시험 직전의 임시 순환 덱이다. 광역 시험 카드만 대조용 단일 불기둥으로 교체하며 정식 원복값으로 자동 복구하지 않는다. 절차는 [09 광역 시험](09_프로토타입_제작절차.md#aoe-trial-procedure)을 따른다.
