## 사양 블록 (여기부터 복사)

```
# Scroll Hunter 프로토타입 — 공통 사양

## 이 프로토타입의 목표
적의 캐스팅을 읽고 한정된 코스트를 배분하는 것이 재미있는지 검증한다.
아트는 전혀 필요 없다. 큐브/캡슐과 Unity 기본 UI만 사용한다.
재미 검증이 끝나기 전에는 모델, 이펙트, 사운드를 넣지 않는다.

## 전투 구조
- 실시간. 플레이어 1인 vs 적 최대 3체
- 플레이어는 코스트만 충분하면 아무 때나 카드를 쓸 수 있다 (쿨타임 없음)
- 턴 개념 없음. 행동 게이지(ATB) 없음

## 자원 — 코스트
- 초당 0.8 충전
- 상한 10, 초과분 소멸
- 전투 시작값 3

## 카드 — 덱과 손패
- 덱 8장(순서 있음) → 앞 4장이 손패(QWER) → 나머지 4장이 대기열
- 유효한 카드 입력 수락 즉시 그 카드는 덱 맨 아래로 이동, 대기열 맨 앞이 같은 슬롯에 진입
- 결정론적 순환. 셔플 없음. 등록 순서 그대로
- 손패 교체/버리기 없음 (4일차에 도입 여부 재검토)

## 행동 잠금 (GCD) — 중요
- 카드 사용 후 다음 카드를 쓸 수 없는 시간 = MAX(그 카드의 캐스팅 시간, 최소 GCD 0.4초)
- 즉 캐스팅기는 캐스팅 시간 전체가 잠금이고, 즉발기는 최소 GCD만 적용된다
- 개별 스킬 쿨타임은 없다. 카드 순환이 그 역할을 한다
- 캐스팅 중 다른 카드 입력은 무시한다 (버퍼 저장 없음)
- 캐스팅은 스스로 취소할 수 없다
- 캐스팅 중 기절당하면 캐스팅 취소, 코스트는 반환하지 않는다
- 포션(Shift)에는 행동 잠금이 적용되지 않는다
- 손패 슬롯 위에 남은 잠금 시간을 소수점 1자리로 표시한다

## 전투 진행
- 런 1회 = 전투 5회 (잡몹 4 + 보스 1). 선형 진행, 분기 없음
- 전투 종료 시 보상 1회 → 덱 리빌딩 → 다음 전투
- HP는 전투 사이에 이월된다. 방어도는 전투 종료 시 소멸한다

## 적 캐스팅 3색
- 초록(Green): 일반 공격. 대응 불필요
- 주황(Orange): 기절 공격. 차단 카드로 캐스팅 취소 가능
- 빨강(Red): 대형 피해. 방어도 카드로 흡수. 차단 불가
- 입력 시 대상이 캐스팅 중이면 사용 가능. 침묵 시전 0.2초 뒤에도 초록·주황 캐스팅 중이어야 성공하며, 그전에 발동하면 실패하고 경직 없음(코스트·카드는 소모)
- 적끼리 발동이 겹치지 않도록 최소 0.5초 간격 강제

## 적 공격 구성과 패턴 쿨다운 — 중요
- 모든 적이 초록(기본 공격)을 보유한다. 주황·빨강은 그 위에 추가되는 공격이다
- 보유 조합: A 초록 / B 초록+주황 / C 초록+빨강 / D 초록+주황+빨강 / 보스 전부
- EnemyData는 색 하나가 아니라 공격 리스트를 갖는다
- 패턴 쿨다운은 시간이 아니라 초록 사용 횟수로 센다
  주황: 사용 후 초록 1회 경과 / 빨강: 사용 후 초록 2회 경과 / 초록: 쿨다운 없음
- 우선순위 빨강 > 주황 > 초록
- 행동 선택 규칙 (순서대로 판정)
  1. 직전 행동이 주황이나 빨강이었다면 반드시 초록을 사용
  2. 쿨다운이 끝난 상위 공격 중 우선순위가 가장 높은 것 사용
  3. 없으면 초록 사용
- 발동 후 경직: 초록 1.0초 / 주황 1.5초 / 빨강 2.0초 / 차단 성공 시 2.5초
  경직 시간 = 발동부터 다음 캐스팅 시작까지의 간격
- 차단 성공 시 그 공격의 쿨다운도 소모된다 (한 번 쓴 것으로 친다)
  경직이 풀리면 반드시 초록이 먼저 온다: 주황(차단) → 초록 → 주황
  단 초록을 차단한 경우에는 초록 횟수를 올리지 않는다
- 주의: 플레이어 카드에는 쿨타임이 없다. 이것은 적 전용 규칙이다

## 타겟팅
- 타겟 개념은 하나뿐이다. 차단 전용 타겟이나 순환 키를 만들지 말 것
- 딜/단일과 차단은 타겟 1체, 딜/광역은 적 전체, 방어는 자신
- 타겟 조작: 마우스 클릭 또는 좌우 방향키
- 전투 시작 시 1번 적 자동 지정. 타겟이 죽으면 자동으로 다음 생존 적으로 이동
- 타겟 위에 조준 마커 표시
- 차단 카드는 타겟이 캐스팅 중이 아니면 슬롯 비활성 (입력 불가)
- 타겟이 빨강 캐스팅 중이면 활성이되 사용 시 실패하고 코스트를 소모한다

## 카드 효과 적용 시점 — 중요
- 카드 효과는 캐스팅이 끝나야 적용된다. 누르는 순간이 아니다. 코스트만 즉시 빠진다
- 타이머가 둘이다: 효과까지 = 캐스팅 시간 / 다음 입력까지 = MAX(캐스팅 시간, 최소 GCD)
- 캐스팅 중 기절당하면 취소된다. 코스트는 반환하지 않는다. 카드는 입력 수락 시 이미 순환했으므로 추가 순환하지 않는다
  효과만 발생하지 않는다. 코스트와 카드를 둘 다 잃는 것이 기절의 대가다
- 기절이 행동 잠금을 대체한다. 기절이 풀리면 곧바로 쓸 수 있다

## 손패 슬롯 비활성 표시 — 사유 4가지를 구분할 것
- 코스트 부족: 해당 슬롯만. 코스트 숫자를 빨갛게
- 타겟이 캐스팅 중 아님: 차단 카드만. 자물쇠 아이콘 또는 점선 테두리
- 행동 잠금 중: 손패 전체. 회색 + 남은 시간 숫자
- 기절 중: 손패 전체. 보라 계열 + 남은 시간 숫자 + 화면 중앙에 기절 표시
- 행동 잠금과 기절은 둘 다 손패 전체라 색으로 갈라야 한다.
  중앙 표시는 기절에만 붙인다. 색은 원인을, 중앙 표시는 상태를 알린다
- 기절·효과 지연은 구현 완료. 아래 2026-09-16 변경 사양도 **구현 반영·검증 완료**다

## 단일 / 광역 밸런스
- 손익분기 **적 2체.** 같은 코스트 기준 광역 피해량 = 단일 피해량 × 0.5
- 광역기의 대가는 코스트가 아니라 **캐스팅 시간** (0.8~1.2초)
- 광역기 코스트를 올리면 피해량도 비례해 올릴 것

## 대응 수단
- 차단(Interrupt): 캐스팅 중인 적 대상. 성공 시 캐스팅 취소 + **2.5초 경직**
- 방어도(Shield): 플레이어에게 부여. 피해는 방어도 → HP 순으로 차감

## 플레이어
- HP 500, 방어력 20, 크리티컬률 15%
- **공격력 스탯 없음.** 피해는 스킬에 적힌 피해량(절대값)으로만 결정된다
- SkillData에는 계수가 아니라 damage(int) 필드를 둘 것
- HP는 전투 사이에 회복되지 않는다 (소모성 자원)
- 회복 포션은 런 전체 3회. 최대 HP의 50% 회복. 행동 잠금 미적용
- 피해 공식: float raw = 피해량 * 타수 * 100f / (대상방어력 + 100f) * 크리배율
- damage는 int 필드, 계산 중간값은 float, 정수화는 최종 1회만
- 곱셈을 먼저 할 것. (1 - def/(def+100)) 형태는 부동소수점 오차로 25가 24가 된다
- 정수화: if (raw <= 0f) return 0; else return Mathf.Max(1, Mathf.FloorToInt(raw + 0.5f));
- Mathf.RoundToInt와 Math.Round는 둘 다 은행가 반올림(0.5→0, 2.5→2)이므로 쓰지 말 것
- 최소 피해 1. 단 피해량 0인 카드(방어·차단)는 0을 유지할 것
- 검증값 (플레이어 방어력 20): 30 → 25, 40 → 33, 150 → 125

## 확정 사항 (10_결정사항_로그 기준)
- 손패 슬롯 위치는 고정. 카드가 왼쪽으로 밀리지 않는다
- 캐스팅은 스스로 취소할 수 없다
- 캐스팅 중 다른 카드 입력은 버퍼에 저장하지 않고 무시한다

## 코딩 규칙 (반드시 지킬 것)
- 모든 수치는 [SerializeField] 또는 ScriptableObject로 인스펙터에 노출. 하드코딩 금지
- 스킬/적 데이터는 ScriptableObject로 분리
- **Unity 6.3 LTS (6000.3.18f1), C#, URP 기준**
- **입력은 구형 Input API(Input.GetKeyDown)를 사용한다.**
  프로젝트의 Active Input Handling이 "Both"로 설정되어 있다.
  Input System 패키지 방식으로 작성하지 말 것.
- API가 Unity 6에서 사용 중단(Obsolete)된 것이라면 대체 API를 알려줄 것
- 한 번에 한 기능씩. 요청하지 않은 기능(사운드, 파티클, 세이브 등)은 만들지 말 것
- 만든 뒤 "어떻게 실행해서 확인하는지"를 항상 함께 설명할 것
```

### 2단계 — 적과 캐스팅 바

```
2단계. 적을 추가한다.

```
3단계. 여기가 이 프로토타입의 핵심이다.

침묵 코스트 2, 시전 0.2초. 입력 시 캐스팅 중이어야 사용 가능하고, 효과 적용 시에도 초록·주황 캐스팅 중이어야 성공한다. 먼저 발동하면 실패·경직 없음. 코스트·카드는 실패해도 소모된다.

   - 화면에 방어도 수치 표시
3. 타겟팅: 마우스 클릭으로 적 선택. 선택된 적에 표시

## 4일차 판단 기준

**판정 절차는 `09_프로토타입_제작절차.md` 4단계 ④~⑥을 따른다.** 같은 빌드·덱·적 구성·시작 상태·배속·포션 조건에서 공격만 약 5회와 공격+대응 약 5회를 비교하고, 사용 순서와 플레이어의 의도를 함께 기록한다. 계측 구현 완료와 재미 검증 완료는 구분한다.

| 관찰 | 함께 볼 항목 | 판단 원칙 |
|---|---|---|
| 생존 시간이 늘어남 | 승패·처치 수·남은 HP | 오래 버틴 것만으로 성공 판정하지 않음. 승리 시간과 패배까지 버틴 시간을 따로 비교 |
| 차단·방어 사용이 적음 | 사용 기회·코스트·카드 접근성·잠금·UI 이해·조기 사망 | 원인을 구분한 뒤 판단. 사용 횟수만으로 핵심 가설 실패라 단정하지 않음 |
| 사용 카드가 편중됨 | 피해 효율·적 위협·대응 필요성 | 카드별 횟수가 고르다고 좋은 것은 아님 |
| 카드 순서가 반복됨 | 위협·손패·코스트 조건 | 같은 상황의 같은 선택은 실패가 아님. 조건 변화에 따른 선택 변화를 확인 |
| 끌어오기 장면이 있음/없음 | 당시 의도·사용 순서·대응 기회 | 한 장면은 판단 발생의 근거이며 설계 전체의 성공 증명은 아님. 없으면 해당 상황이 있었는지부터 확인 |
| 코스트 부족·상한 손실이 많음 | 입력 원인·의도적 대기·실제 손실량 | 곧바로 회복량을 0.6 또는 1.0으로 바꾸지 않음. 원인을 기록하고 변경은 별도 결정 |

묶음별 승률과 회차별 결과를 함께 보고, 시간·HP·처치 수의 평균과 범위를 비교한다. 승리와 패배의 전투 시간은 구분한다. 약 5회씩의 시험은 원인을 찾기 위한 초기 비교이며 확정적인 통계 검증으로 취급하지 않는다.

관찰을 정리한 뒤 유지 / 추가 시험 / 한 가지 수치 변경 중 다음 행동을 정한다. 수치·사양을 바꾸기로 결정한 경우에만 결정 로그와 관련 문서를 함께 갱신한다.

**기존 숫자의 해석:** 대응 사용 2회 이상, 고른 카드 사용, 전투 40±10초를 이번 비교의 일률적인 합격선으로 사용하지 않는다. 전투 시간은 기존 기획 목표와의 차이를 살펴보되, 승패·처치·HP·전투 구성을 함께 확인한 뒤 조정 여부를 결정한다.

## 2026-09-16 차단·손패 규칙 변경 반영

침묵은 코스트 **2**, 시전 **0.2초**, 차단 성공 경직 **2.5초**. 초록·주황은 차단 가능하고 빨강은 차단 불가. 입력 시 대상이 캐스팅 중이어야 사용 가능하며, 효과 적용 순간에도 초록·주황 캐스팅 중이어야 성공한다. 그전에 적 공격이 발동했으면 차단 실패이며 경직을 주지 않는다. 빨강 또는 시전 중 적 캐스팅 종료로 실패해도 코스트·카드는 소모된다.

유효한 입력을 수락하는 즉시 코스트를 소모하고, 사용 카드를 덱 맨 아래로 보낸 뒤 대기열 맨 앞 카드를 같은 손패 슬롯에 넣는다. 새 카드는 행동 잠금 중 사용할 수 없다. 효과는 시전 완료 시 적용한다. 자발적 취소는 불가하며, 기절에 의한 강제 취소 시 효과만 취소하고 코스트 반환·추가 카드 순환은 하지 않는다. 비캐스팅 대상 차단 등 거절된 입력은 코스트·카드를 소모하지 않는다.

**상태:** 문서 반영 완료 + **구현 반영·실행 검증 완료 (2026-09-16).** 침묵 2코스트, 차단 경직 2.5초, 초록 차단 성공, 입력 수락 즉시 순환, 기절 취소 시 이중 순환 없음, 시전 중 적 선발동 시 실패·코스트/카드 소모까지 플레이 모드에서 확인했다. 이전 4초 경직 관찰은 구사양 시험 기록이다. 플레이어가 주황 공격으로 받는 기절은 **2초 유지**.
