# 2026-09-18 UI 실행 확인 — Codex

## 범위와 방법

- Unity MCP로 Battle 씬의 Play 모드에서 1회 기능 확인. A+B+C 구성, 현재 임시 카드값 유지.
- 실제 키보드 입력 대신 기존 `DeckSystem.TryUseSlot`을 호출했다. 적 공격·시간 경과는 실제 게임 루프로 진행했다.
- 실행 중 UI 텍스트·색·상태와 코스트·HP를 읽었다. 스크린샷 렌더링 검사나 사용자 재미 계측은 아니다.
- 코드·씬·에셋 수정·저장 없음. 테스트용 콜백은 종료 시 해제했다. 실행 중에만 켠 runInBackground는 기존 false로 복구하고 Play 모드를 종료했다.

## 제한

- 승리·타겟 사망 자동 이동, 실제 QWER 입력, 종료 후 키 입력, 캐스팅 중 기절 취소는 이번 시험에서 검증하지 않았다.
- 이번 패배 시각은 방패 1회·침묵 1회 사용한 기능 시험 결과다. 무입력 기준이나 플레이어 밸런스 계측에 합치지 않는다.
- 가독성·카드 오사용 감소·재미는 이 시험으로 확정하지 않는다. 차단 잠김의 어두운 글자는 그대로이며, 사용자가 최소 프로토타입 범위에서 수용한 상태다.
- 임시 카드값 정식 채택이나 사양 변경 결정은 없다.
