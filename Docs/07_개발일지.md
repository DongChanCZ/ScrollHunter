  - **패턴 쿨다운을 카운터 2개(`greenAtLastOrange`, `greenAtLastRed`)로만 구현.** 상태 머신이나 스케줄 테이블 없이 「초록 누적 횟수 − 마지막 사용 시점」 비교만으로 D형 `🔴→🟢→🟠→🟢→🔴`이 자동 생성된다. 문서가 말한 "별도 스케줄링 로직 불필요"가 코드에서도 그대로 성립

  - **기절 중 손패 표시 규칙을 사양으로 확정** (`02` §6.5.4, `10` A9·A10). 기존에는 `02` E10의 "입력 무시" 한 줄뿐이라 플레이어가 왜 못 누르는지 알 방법이 없었다. 행동 잠금과 기절이 둘 다 「손패 전체 + 남은 시간」이라 화면이 똑같아지는 게 문제였고, **슬롯 색(회색/보라) + 화면 중앙 표시**를 둘 다 넣기로 했다. 색은 원인을, 중앙 표시는 상태를 알린다. 구현은 2차
  - **단 초록을 차단했을 때는 초록 횟수를 올리지 않는다** (`10` M12). 초록 횟수는 플레이어가 화면을 보고 직접 세는 값이라, 취소된 캐스팅을 세면 플레이어가 센 숫자와 내부 값이 어긋난다. 초록은 쿨다운도 없어 소모시킬 대상 자체가 없다
  - 구조 변경(카드 효과를 캐스팅 완료 시점으로 지연)과 기절은 **2차로 분리.** 회귀 위험이 커서 1차를 커밋한 뒤 시작한다
  - **[2차] 카드 효과를 캐스팅 완료 시점으로 옮겼다** (`10` A11). 기존에는 누르는 즉시 효과가 나고 잠금만 남아서, 「캐스팅 중 기절당하면 취소」(E02c)를 걸 대상 자체가 없었다. 불기둥(캐스팅 1.2초)도 0초에 피해가 들어갔다. 타이머를 둘로 나눴다 — 효과까지 `캐스팅 시간`, 다음 입력까지 `MAX(캐스팅, 최소 GCD)`
  - **[2차] 캐스팅이 끊기면 코스트와 카드를 둘 다 잃는다** (`10` A12). 사양에 없던 부분이라 판단이 필요했다. 처음에는 "효과가 안 났으니 카드는 손패에 남긴다"로 만들었으나, 그러면 다시 누르면 그만이라 기절의 대가가 코스트 하나로 줄어든다. **주황을 막지 못한 순간의 무게**를 살리는 쪽으로 확정했다 — 대응 카드가 순환에서 한 바퀴 밀려나는 것까지가 그 값이다. E02c의 「손해가 두 배」가 이것
  - **각진 바를 만들려니 `Image.fillAmount`를 못 쓰게 됐다.** 둥근 모서리는 Unity 기본 `UISprite` 때문인데, 스프라이트를 빼면 각진 사각형이 되는 대신 `fillAmount`가 동작하지 않는다(스프라이트가 있어야 하는 기능). 채움을 **오른쪽 앵커(`anchorMax.x`) 이동**으로 바꿔 둘 다 얻었다. 계산은 `Enemy.SetFill()` 한 곳에만 둔다
  - **적 바를 화면 고정으로 옮기면서 생명주기가 갈렸다.** 월드 공간일 때는 바가 적의 자식이라 적을 끄면 같이 사라졌는데, `Canvas` 아래로 옮기니 적만 꺼지고 바가 화면에 남는다. `Enemy.Die()`에서 `castBarRoot`를 직접 끄도록 했다. **부모가 바뀌면 "누가 이걸 끄는가"를 다시 정해야 한다**는 걸 놓칠 뻔했다
  - **[2차] 기절이 행동 잠금을 대체한다** (`10` A13). 기절 2초가 GCD 0.4초보다 항상 길어서, 둘을 겹쳐 세면 기절이 풀린 뒤에도 잠깐 더 못 쓰는 이상한 구간이 생긴다
