| 9~11 | 적 4종 패턴 + 보스. 보상 3택1. **11일차 기능 동결** | ☐ |
| 12~13 | VARCO 3D 모델 교체, 라이팅, 포스트 프로세싱 | ☐ |
| 14~15 | 카메라 연출, 배경, VFX 통일 | ☐ |
| 16~17 | UI 다듬기, 사운드, 타이틀·결과 화면, 전환 | ☐ |
| 18 | 밸런싱 실측, 버그 | ☐ |
| 19 | **빌드하고 남에게 테스트**, 치명적 버그만 수정 | ☐ |
