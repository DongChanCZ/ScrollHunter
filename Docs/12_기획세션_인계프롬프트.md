## 프로젝트 배경

2023년 팀 프로젝트 「Soul Wanderer」(이하 SW)의 전투 시스템을 1인 재설계하는 프로젝트다.
SW에서 나는 기획을 담당했고 구현은 팀원이 했다. 이번에는 기획과 구현을 모두 혼자 한다.

목적은 두 가지다.
1. 수업 과제 — 완성된 게임 결과물이 남아야 하고, VARCO 3D(생성형 3D)를 활용해야 한다
2. 포트폴리오 — 지망 회사는 넥슨 메이플스토리 계열(1순위), 넥슨게임즈 블루아카이브 계열

출시를 전제로 만들되, 20일 결과물은 출시 빌드가 아니라 확장 가능한 완결형 런이다.

## SW 분석에서 나온 문제 (이번 재설계의 출발점)

- P0: 문서와 구현이 불일치. 두 기획서 모두 최종 빌드를 설명하지 못했다.
  전투 문서에는 실제로 있던 덱·손패 순환이 없었고, 맵 문서는 규칙(사각 타일)과
  예시·구현(육각 타일)이 같은 문서 안에서 어긋났다
- P1: 적을 관찰할 이유가 없었다. 캐스팅 바 3색(초록/주황/빨강)을 예고했지만
  대응 수단이 설계되지 않아 색이 장식이 되었다
- P2: 맵 선택에 정보와 대가가 없었다 (이번 범위 밖)
- P3: 스코프 과다. 두 문서 모두 후반부가 제목만 있고 비어 있었다

종합 진단: 시스템은 정교하게 설계했으나, 플레이어가 매 순간 무엇을 고민하는지는
설계하지 않았다.

## 현재 설계 (핵심만)

실시간 로그라이크 카드 전투. 플레이어 1인 vs 적 최대 3체.

- 코스트가 실시간 충전(초당 0.8, 상한 10). 쿨타임 없음
- 덱 8장 → 앞 4장이 손패(QWER) → 사용한 카드는 덱 맨 아래로 (결정론적 순환)
- 행동 잠금 = MAX(캐스팅 시간, 최소 GCD 0.4초)
- 적 캐스팅 3색에 대응 수단을 부여한 것이 이번 재설계의 핵심
  초록=대응 불필요(차단 가능) / 주황=차단 카드 / 빨강=방어도 카드
- HP는 전투 사이에 이월된다. 방어도는 전투 종료 시 소멸
- 런 1회 = 전투 5회. 전투 후 보상 3택1(카드 2 + 패시브 1) → 덱 리빌딩
- 런 종료 시 계승 1개 (카드는 시작 덱 슬롯 덮어쓰기, 패시브는 누적)
- 플레이어·적 모두 공격력 스탯 없음. 피해는 카드·적에 적힌 절대값

블루아카이브의 코스트+손패 구조를 참조했으나 무작위 추첨 대신 결정론적 순환을 택했다.
그래서 "다음 카드를 정확히 안다"는 것을 약점이 아니라 플래닝 도구로 쓰는 방향이다.

5. 문서 간 모순을 발견하면 즉시 말해라. 실제로 여러 번 있었다

6. 판단은 숫자로 해라. "재미있을 것 같다"가 아니라 "코스트당 기대 피해 비율이

7. 내가 틀린 지시를 하면 따르지 말고 확인해라. 실제로 문서의 반올림 지시가

## 인계 후 첫 3개 질문 (검증용)

새 세션이 제대로 맥락을 잡았는지 확인하는 용도입니다.

1. **"최소 GCD 값이 몇이고 왜 그 값이야?"**
   → 0.4초. 0.3은 코스트 회복(0.8/초)보다 빨라 실효가 낮다는 답이 나와야 함

2. **"이 게임에서 광역기가 보스전에 약한 이유가 뭐야?"**
   → 손익분기가 적 2체라서, 적 1체인 보스전에서는 단일기의 절반이라는 답

3. **"P0가 뭐고 이번에 어떻게 대응하고 있어?"**
   → 문서-구현 불일치. 변경 이력 표 + 개발일지 + 결정사항 로그로 대응

## 2026-09-16 차단·손패 규칙 변경 반영

침묵은 코스트 **2**, 시전 **0.2초**, 차단 성공 경직 **2.5초**. 초록·주황은 차단 가능하고 빨강은 차단 불가. 입력 시 대상이 캐스팅 중이어야 사용 가능하며, 효과 적용 순간에도 초록·주황 캐스팅 중이어야 성공한다. 그전에 적 공격이 발동했으면 차단 실패이며 경직을 주지 않는다. 빨강 또는 시전 중 적 캐스팅 종료로 실패해도 코스트·카드는 소모된다.

유효한 입력을 수락하는 즉시 코스트를 소모하고, 사용 카드를 덱 맨 아래로 보낸 뒤 대기열 맨 앞 카드를 같은 손패 슬롯에 넣는다. 새 카드는 행동 잠금 중 사용할 수 없다. 효과는 시전 완료 시 적용한다. 자발적 취소는 불가하며, 기절에 의한 강제 취소 시 효과만 취소하고 코스트 반환·추가 카드 순환은 하지 않는다. 비캐스팅 대상 차단 등 거절된 입력은 코스트·카드를 소모하지 않는다.

**상태:** 문서 반영 완료 + **구현 반영·실행 검증 완료 (2026-09-16).** 침묵 2코스트, 차단 경직 2.5초, 초록 차단 성공, 입력 수락 즉시 순환, 기절 취소 시 이중 순환 없음, 시전 중 적 선발동 시 실패·코스트/카드 소모까지 플레이 모드에서 확인했다. 이전 4초 경직 관찰은 구사양 시험 기록이다. 플레이어가 주황 공격으로 받는 기절은 **2초 유지**.

|---|---|---|---|
| 2026-09-16 | 침묵·차단 | 코스트 ~~4~~ → **2**, 성공 경직 ~~4초~~ → **2.5초**, 초록 차단 허용 | 사용자 확정 |
| 2026-09-16 | 성공 판정 | 입력 가능 여부와 시전 완료 시 차단 성공 여부 분리 | 사용자 확정: 먼저 발동한 공격은 차단하지 못함 |
| 2026-09-16 | 손패 교체 | 유효 입력 수락 즉시 순환. 기절 취소 시 이중 순환 금지 | 사용자 확정: GCD가 다음 카드 사용을 제한 |
