# 후속 3단계 — 광역 1종 비교계측 (2026-09-21)

**상태: 사용자가 제출한 플레이 로그 4건·플레이어 답변 5항목·1차 해석 정리 완료. 전체 플레이 횟수와 회차별 정지 이력은 미확인. 수동 정지를 포함한 탐색 기록이며 정식 밸런스 채택·시험값 변경·추가 구현은 미결정이다.**

이 문서의 회차는 전체 플레이의 연속 번호가 아니라 **이 대화에 제출한 순서**다. 시험값·계획·복구 기준은 [시험안](260921_광역1종_시험안.md), 구현 당시 함수 호출 검증은 [구현검증](260921_광역1종_구현검증.md)에 있다. 여기에는 실제 제출 결과와 플레이 의도만 모은다. 이전 UI·적 구성별 계측과 한 묶음으로 합치지 않는다.

## 1. 근거와 실제 조건

- 제출 순서: A+B+C 단일 불기둥 → 광역 → 광역 → 단일, 각 덱 2건. 카드 이름·피해·입력과 결과 시각으로 구분했다.
- 사용자는 피해 계산을 위해 툴팁이 필요하면 수동 정지를 사용했다고 답했다. **회차별 정지 여부·횟수·시간은 미확인**이다. 계획의 무정지 조건을 충족했다고 기록하지 않는다.
- 현재 저장 코드에서 배속 전환·포션 사용 기능은 미구현이며 전투는 1배속으로 시작한다. 각 과거 실행의 코드·UI 버전 동일성이나 외부 배속 조작 여부까지 로그가 증명하는 것은 아니다. 실제 배속을 사용했다는 진술은 없다.
- 성공 카드 사용의 호출 스택: 1회차 좌클릭 경로 4회·키보드 경로 18회, 2/3/4회차 키보드 경로 9/20/23회. QWER 표기 자체가 장치를 뜻하는 것은 아니다.
- 전투 시간은 게임 내 시간이다. 수동 정지 시간은 빠지므로 실제 소요 시간·판단에 쓴 시간으로 해석하지 않는다.
- 사용자는 광역 뒤 방어 준비 지연으로 패배한 경험을 설명하면서 “내가 올린 계측은 승리했을때의 플레이를 올림”이라고 덧붙였다. **제출 2회차 원문은 27.52초 패배**다. 기록의 승패는 그대로 두며, 미공유 시도 수·승패·선별 제출 여부와 해당 실패 장면은 추가 확인이 필요하다.
- 전체 시도 수가 없으므로 제출 4건을 전체 승률이나 패배 확률로 환산하지 않는다. 모든 회차가 조건을 통제한 연속 시험이었다고도 가정하지 않는다.

## 3. 피해·HP 재계산

로그의 카드 피해에는 남은 적 HP보다 큰 과잉 피해가 포함된다. 아래 실효 피해는 적 HP와 사건 순서를 재구성한 값이며 게임에서 자동 계측한 새 항목은 아니다. 제출 광역 두 번은 모두 3체가 살아 있고 각 HP가 60 이상일 때 적용돼 대상별 60·합계 180을 모두 유효하게 적용했다.

| 항목 | 1회차 | 2회차 | 3회차 | 4회차 |
|---|---:|---:|---:|---:|
| 카드 피해 로그 합계 | 968 | 463 | 993 | 975 |
| 적 HP 실제 감소 합계 | 900 | 420 | 900 | 900 |
| 과잉 피해 | 68 | 43 | 93 | 75 |
| 방어력 적용 후 받은 피해 | 907 | 757 | 898 | 857 |
| 방어도 흡수 | 435 | 240 | 418 | 460 |
| HP 차감 로그 합계 | 472 | 517 | 480 | 397 |
| 실제 HP 감소 | 472 | 500 | 480 | 397 |

2회차는 마지막 피격 25 직전 HP가 8이므로 HP 차감 로그 517 중 17은 사망 시 초과 피해다. HP 계산 오류로 보지 않는다. 2회차 종료 시 A·B HP는 각 240으로 재구성된다. 승리 회차의 종료 요약 뒤 마지막 카드 결과가 출력되는 것은 같은 처치 처리의 로그 순서이며 그것만으로 종료 후 추가 공격이라 하지 않는다.

## 4. 판단 장면과 인과의 범위

### 광역 두 번과 방패 준비

| 장면 | 입력 → 효과 | 로그·순환 재구성 | 해석 |
|---|---|---|---|
| 2회차 첫 광역 | 13.26 → 15.27초 | 3체 합계 180. 입력 즉시 W에 수정방패 진입, 잔여 코스트 0.62 | 시전 종료 때도 약 2.23코스트. 회복만 고려하면 약 16.24초에 3 확보(입력 로그 반올림·프레임 오차 있음). 시전 종료 후에는 코스트 대기가 제약 |
| 2회차 후속 방패 | 16.62 → 16.82초 | 빨강 전에 방어도 120 적용. 다음 빨강 125 중 120 흡수, HP -5 | 이 장면은 방패가 빨강 뒤에 적용된 사례가 아니다. 미공유 실패 장면과 구분 |
| 3회차 첫 광역 | 13.45 → 15.45초 | 3체 합계 180. 입력 즉시 Q에 수정방패 진입, 잔여 코스트 1.77 | 약 14.99초에 3코스트 확보 가능하지만 15.45초까지 행동 잠금. 이 구간은 잠금이 제약 |
| 3회차 후속 방패 | 15.67 → 15.87초 | 방어도 120 적용 뒤 초록이 25 소비. 다음 빨강에서 95 흡수, HP -30 | 방패가 먼저 들어왔어도 중간 초록 피격 때문에 빨강 흡수량이 달라짐 |

손패는 입력 수락 즉시 교체된다(10 A14, DeckSystem.TryUseSlot). 사용자는 “방패가 들어오는 사이클이 늦어졌다”고 표현했지만, 위 장면의 정확한 구분은 **방패 진입 완료 → 행동 잠금 또는 코스트 대기 → 방패 시전 → 효과 적용**이다. 긴 시전이 이후 카드 사용과 추가 순환을 늦출 수 있다는 체감과, 손패 교체 자체가 시전 완료까지 지연된다는 주장은 다르다. 광역의 긴 시전만으로 패배 원인·확률을 확정하지 않는다.

### 단일 집중·광역 보류·차단

- **1회차:** 단일 불기둥 13.27→14.47초 C에 78, 54.09→55.30초 A에 78. 침묵은 B 34.42→34.62초, A 52.24→52.44초에 성공했다. 두 침묵의 개별 세부 이유는 아래 사용자 공통 답변 범위로만 해석한다.
- **2회차:** 2.75초 서리화살이 기절로 취소됐다. 취소 카드가 광역이었다고 기록하지 않는다. C는 광역 전 HP 181이었고 25.07초에야 처치됐다. 초기 피해 손실·카드 순서가 함께 달라 패배를 광역 하나에 귀속하지 않는다.
- **3회차:** 광역 전 C HP 113→53, 18.04초 서리화살로 처치. B를 21.31초에 한 번 공격한 뒤 A로 전환했다. 22.91초 W에 광역이 재진입해 끝까지 남았고, 37.04초에는 코스트 4.65로 화염탄을 선택했다. 접근성·코스트만으로 미사용을 설명할 수 없으며 방어 준비 지연을 피하려 했다는 사용자 답변과 연결한다.
- **4회차:** 서리화살 13.27→13.58초에 C HP 129→69, 단일 불기둥 14.45→15.65초에 처치. 제출 회차 중 C를 가장 빨리 제거해 빨강 피격이 한 번뿐이었다. 전체 승리 시간은 가장 길지만 HP는 가장 많이 남았다.
- **4회차 코스트 부족:** 31.34·31.60초 수정방패 입력 거절 뒤 32.72초 사용, 32.92초 효과. 입력 2회를 서로 다른 실패 전략 2건으로 세지 않는다.
- **4회차 침묵:** B 26.54→26.74초, B 42.48→42.68초, A 54.73→54.93초에 성공. B HP 10에서도 사용한 이유를 개별 장면에 대해 추가로 단정하지 않는다.

## 5. 플레이어 답변과 해석

2026-09-21 사용자의 다섯 답변을 의미가 바뀌지 않게 요약했다. 진술한 의도와 로그가 증명하는 결과를 구분한다.

| 질문 | 플레이어 답변 | 허용되는 해석·한계 |
|---|---|---|
| 조건 | 배속·포션 구현 여부는 몰랐으며, 피해 계산용 툴팁을 보려고 필요하면 수동 정지를 사용 | 정지 포함 탐색으로 분류. 회차별 이력은 미확인. 무정지 실시간 읽기 검증으로 확대하지 않음 |
| 광역 사용 이유 | 코스트가 모였고 기절 공격 타이밍이 아니며 적 3체라 이득이라고 생각해 시전. 긴 시전으로 방패 준비가 늦어져 빨강에 크게 맞고 패배한 경험도 있음 | 다수 대상 효율과 적 기절 타이밍을 고려한 선택 의도. 실패 경험은 관찰로 보존하되 제출 2·3회차의 방패 상황과 혼동하지 않음 |
| 두 번째 광역 미사용 | 방패가 들어오는 사이클이 늦어져 패배 위험이 높아진다고 느꼈음 | 방어 준비를 위해 광역을 보류한 의도. 실제 패배 확률 상승의 통계적 입증은 아님 |
| 3회차 B→A 전환 | 과잉 피해가 많다고 느껴 HP 여유가 있을 때 피해를 분배하고 먼저 처치할 수 있는 적을 처리 | 의도적 타겟 변경. 과잉 피해 최소화나 최적 처치 순서가 실제로 달성됐다는 뜻은 아님 |
| 침묵 목적 | 주로 HP 보존과 짧은 시전으로 손패를 빠르게 순환시키기 위함 | 차단과 순환의 복합 목적. 0.2초 시전과 최소 0.4초 행동 잠금을 구분. 짧은 잠금은 일부 공격 카드와 공유하므로 침묵만의 독점 이점으로 보지 않음 |

**1차 해석:** 광역 효율·상대 기절 타이밍·다음 방어 준비·처치 대상 사이의 선택 의도가 확인됐다. 3회차 광역 보류를 카드 미인지로 단정하지 않는다. 이전의 “저코스트 공격으로 침묵의 순환 역할이 사라졌다”는 관찰을 모든 상황에 일반화하지 않는다. 이번에는 HP 보존과 순환을 함께 노렸다는 후속 근거가 있다.

**아직 결론 내리지 않는 것:** 광역이 단일보다 우수/열세, 긴 시전이 패배의 단독 원인, 정식 채택, 무정지 실시간 판단의 편의성, 반복 플레이의 재미. 특히 제출 두 광역 모두 정상 완료됐으므로 시전 취소 위험이 충분히 실측됐다고 하지 않는다.

## 7. 문서 정리 시점의 저장 상태와 작업 범위

- 원시 로그를 다시 읽고 입력·효과·피격·종료 요약을 대조했다. 게임을 새로 실행하거나 새 회차를 생성하지 않았다.
