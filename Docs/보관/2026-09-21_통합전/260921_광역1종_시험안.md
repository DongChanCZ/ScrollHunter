## 3-1. 시험 목적과 카드 후보

**제안하는 질문:** 여러 적의 HP를 함께 깎는 선택이 생기면, 위협적인 적부터 단일 공격으로 처치할지와 광역 시전을 언제 감수할지에 대한 판단이 생기는가?

근거: `260918_3단계.md`의 사용자 관찰에 광역 부재가 기록돼 있다. 적이 줄자 주황·빨강 캐스팅을 볼 여유가 생겼다는 관찰도 있다. 광역 추가가 캐스팅 읽기 문제를 해결한다고 미리 결론 내리지 않는다.

**사용자 지정:** 불기둥을 광역 카드로 하고, 광역 피해는 코스트 대비 총피해량을 높이는 대신 캐스팅이 긴 방향으로 잡는다. 기존 불기둥 1장의 시험용 변경안으로 작성하며 덱 8장 및 등록 순서, 다른 카드 7장은 유지하는 안을 제안한다.

## 3-2. 시험값과 비교 기준

시험안 작성 당시(2026-09-21) 저장 에셋 확인: 불기둥 3코스트·39피해×2=78·시전1.2초, 연쇄번개 3코스트·25피해×3=75·시전1.0초. 이는 07 D-05의 임시 순환 시험값이며 정식 밸런스 확정값이 아니다. 이 기준 확인 단계에서는 Unity를 실행하지 않았고, 이후 기능 확인과 실플레이는 각각 구현검증·비교계측 문서에 기록했다.

| 항목 | 현재 불기둥(대조용 `Skill_FlamePillar`) | 광역 불기둥(시험용 에셋 `Skill_FlamePillar_AoeTest`) |
|---|---|---|
| 코스트 | 3 | 3 |
| 대상 | 타겟 1체 | 효과 적용 시 생존 적 전체 (`10` T3) |
| 대상당 피해·타수 | 39 × 2 = 78 | **30 × 2 = 60** |
| 시전·행동 잠금 | 1.2초·1.2초 | **2초·2초** |
| 추가 효과 | 없음 | 없음 |

이 안은 코스트와 타수를 유지하며 대상·피해·시전시간을 함께 바꾸는 카드 교체 시험이다. 다수 대상 화력과 시전 위험을 묶어서 평가하며, 광역 범위만의 순수 효과를 분리하는 시험은 아니다. 2타의 시간차나 지속 피해를 새로 만드는 제안도 아니다.

| 비교 카드 | 적 1체 총피해 | 적 2체 총피해 | 적 3체 총피해 | 코스트당 총피해(1/2/3체) |
|---|---:|---:|---:|---|
| 현재 단일 불기둥 | 78 | 78 | 78 | 26 / 26 / 26 |
| 광역 불기둥 시험안 | 60 | 120 | 180 | 20 / 40 / 60 |
| 현재 단일 연쇄번개 | 75 | 75 | 75 | 25 / 25 / 25 |

위 표는 방어력0·치명타 없음·모든 대상 생존 및 과잉 피해 무시 조건의 산술값이다. 광역 시험안은 2체부터 현재 불기둥보다 총피해가 높지만 특정 1체를 깎는 피해는 78→60으로 줄고, 대응할 수 없는 시전시간은 1.2→2초로 늘어난다. 시전 중 기절하면 효과가 취소되는 기존 규칙을 유지한다. 실제 처치·HP 보존이 좋아지는지는 미확인이다.

**기존 정식 규칙과의 차이(사용자가 선택한 시험안에 한정한 예외. 시험용 에셋에만 적용되며 정식 규칙은 그대로):**

- `10` T11의 같은 코스트·2체 동등 규칙을 현재 단일 불기둥78에 적용하면 광역 대상당39가 된다. 시험값60은 이보다 높으며, 2체 합계120은78과 동등하지 않다. 사용자가 이 시험값을 선택했지만 2체 동등 규칙을 만족하는 값은 아니다.
- `10` T12의 광역 시전0.8~1.2초 범위에 시험값2초는 들어가지 않는다. 사용자가 피해는 제안과 같게 두고 시전2초를 선택했으므로 해당 시험에 한정한 예외로 기록한다.
- 시험안 승인과 정식 밸런스 채택은 별개다. 원본 T11·T12는 유지한다. 실제 구현은 2026-09-21 사용자 요청으로 시험용 에셋 1개에 한정해 진행했고, 정식 채택은 여전히 미결정이다.

## 3-3. 시험 조건과 순서

아래는 사전 절차다. 구현 당시 함수 호출 확인은 구현검증 문서, 이후 제출된 실플레이 4건과 입력 경로의 부분 확인은 [광역 1종 비교계측](260921_광역1종_비교계측.md) 참조. 좌클릭의 모든 거절 조건·정지 조작 경로까지 검증 완료한 것은 아니다.

1. **입력·기능 확인:** `09`의 후속 UI 실제 입력 확인을 먼저 마친다. 이후 광역이 타겟과 무관하게 생존 적 전체에 한 번씩 적용되는지, 시전 완료 전 피해가 없는지, 기절 취소·종료 후 피해 방지가 유지되는지 확인한다. 이 확인 전투는 플레이 비교 횟수에서 제외한다.
2. **첫 비교는 A+B+C(사용자 선택):** 현재 불기둥 덱과 광역 불기둥 덱을 각각 2회씩, 대조→광역→광역→대조 순으로 배치한다. 4회는 최대 압박 조건에서 문제를 찾는 탐색이며 통계적 결론을 내리는 표본이 아니다. 2초 시전 기회를 잡기 어려울 수 있으므로 광역을 못 쓴 원인도 기록한다.
3. **추가 비교는 미결정:** 첫 4회에서 사용 기회가 부족하거나 압박 때문에 원인을 구분하기 어렵다면 B+C 또는 C 단독 시험을 별도로 검토한다. 지금은 추가 회차를 확정하지 않는다. 서로 다른 적 구성의 승률을 직접 섞지 않는다.

계획상 고정 조건: 같은 코드·UI 버전, 카드 교체 외 덱 순서·임시 카드값 동일, 적 구성별 수치·배치 동일, 새 전투·HP 500·시작 코스트 3·방어도 0, 1배속, 포션 없음. 조작 방식도 묶음 안에서 동일하게 사용한다. 정보는 전투 전에 읽고 비교 중 수동 일시정지를 쓰지 않는 조건을 제안했다.

**실제 수행과의 차이:** 사용자는 피해 계산용 툴팁 확인에 필요하면 수동 정지를 사용했다고 답했다. 회차별 사용 여부·횟수는 미확인이다. 1회차는 좌클릭·키보드 혼용, 2~4회차는 성공 입력 로그상 키보드 경로다. 따라서 무정지·동일 조작 조건을 충족한 시험으로 표시하지 않는다. 수치와 판단 장면은 정보 확인을 포함한 탐색 자료로 사용한다.

처치 순서·카드 사용 순서는 강제하지 않는다. 그것이 관찰할 판단이다. 2026-09-17~18 기록은 배경 자료로만 사용하고 현재 UI에서 대조 회차를 새로 측정한다.

광역 시험을 끝내거나 중단할 경우의 복구 대상은 **시험 직전의 임시 순환 상태**다. 불기둥 단일·3코스트·피해39×2·시전1.2초 등 사전 저장값으로 복구하며, 정식 원복값인 7코스트·90×2피해로 임의 복구하지 않는다. 실제 적용 전 저장값을 다시 확인한다.

판정 질문:

- 적이 여러 체일 때 광역을 고르되, 한 체를 빨리 처치해야 하거나 상대 발동이 임박하면 단일·대응·대기로 바꾸는 장면이 있었는가?

생존 시간 증가나 광역 사용 횟수만으로 성공을 판정하지 않는다. 이 시험안은 2체에서 단일과 피해 합계가 같은 안이 아니다. 높은 총피해만으로 실제 처치 효율이나 적정 밸런스를 확정하지 않는다. 결과에 따라 유지·시험값 한 항목 조정·추가 관찰 중 다음 행동을 정한다.
