## 2. 덱 교체·복구 방법

교체 지점은 **한 칸**뿐이다.

1. Unity에서 `Assets/_Project/Scenes/Battle.unity`를 연다
2. Hierarchy에서 `Systems` 선택
3. Inspector의 **DeckSystem → Starting Deck → Element 7**(8번째, 맨 아래)
4. 시험용으로 바꿀 때: `Skill_FlamePillar_AoeTest` 를 드래그하거나 원형 아이콘으로 선택
5. 대조용으로 되돌릴 때: `Skill_FlamePillar` 로 되돌린다
6. 씬 저장(Ctrl+S)

덱 8장·등록 순서·나머지 7장·적 구성·`minGcd 0.4`·`interruptStagger 2.5`는 어느 쪽이든 그대로다.
DeckSystem 컴포넌트를 지웠다 다시 붙이면 코드 기본값 `interruptStagger = 4f`가 적용돼 씬 값 2.5가 조용히 사라진다. **컴포넌트를 재생성하지 말 것.**

불기둥은 덱 8번째라 초기 손패(화염탄·서리화살·수정방패·침묵)가 아니라 **대기열 맨 뒤**다. 손패에 들어오려면 카드를 4번 써야 한다. 광역을 못 쓴 회차가 있으면 시전 길이 때문인지 덱 진입 지연 때문인지 구분해서 기록해야 한다.

## 3. 기능 확인 결과

확인 방식: Unity Play 모드에서 공개 API와 카드 사용 함수를 호출하고, Game 뷰가 갱신되지 않아 `EditorApplication.Step()`으로 프레임을 하나씩 진행시키며 관찰했다.
이는 실제 `DeckSystem.Update` 타이머 코드 경로를 그대로 실행한 것이지만 **실제 마우스·키보드 입력 경로와 연속 플레이 실측은 아니다.**

### 시험 보조로 강제한 상태 (전부 Play 모드 한정, 저장값 영향 없음)

- 플레이어 HP 99999 — 툴 호출 사이 실시간이 흘러 죽는 것을 막기 위함
- 적 `restTimer` 9999 — 적 공격을 멈춰 피해 계산을 깨끗하게 관찰하기 위함
- 코스트·행동 잠금 강제 설정, 손패 순환을 위해 `CompleteCast` 직접 호출
- 적 HP를 최대치로 되돌려 각 시험의 기준을 맞춤

이 강제 조작들은 **실제 입력 검증도 플레이 실측도 아니다.** 비교 실측 4회에 포함하지 않는다.

## 4. 당시 미확인 항목의 후속 상태

- **실제 입력:** 제출 1회차에 좌클릭 사용 경로 4건, 전 회차에 키보드 사용 경로가 있다. 정지 사용은 사용자 진술로 확인했으나 우클릭·버튼 중 어느 경로인지와 모든 비활성 조건은 미확인이다. 상세는 [광역 1종 비교계측](260921_광역1종_비교계측.md) §6 참조.
- **연속 플레이에서의 체감·실측:** 제출 로그 4건과 플레이어 답변을 [광역 1종 비교계측](260921_광역1종_비교계측.md)에 정리했다. 전체 시도 수·회차별 정지 이력은 미확인이며 정식 채택과 구분한다.
- **대상별 실효 피해·과잉 피해:** 자동 집계는 없다. 제출 4건은 적 HP와 입력·효과 순서를 함께 재구성해 실효 피해·과잉 피해를 별도 계산했다([광역 1종 비교계측](260921_광역1종_비교계측.md) §3). 광역 합계 한 줄만으로 일반적인 모든 장면을 분해할 수 있다는 뜻은 아니다.
- **다른 화면비·해상도에서의 정보창 표시**
- 정보창 피해 문구가 「대상당」인지 「총합」인지 문면으로 구분되지 않는다. 광역 카드에서 `30 × 2`가 대상당 값이라는 점은 이 문서로만 확인된다 — 문구 변경은 이번 범위 밖으로 두었다

## 5. 구현 작업 종료 당시 상태 (비교 플레이 전 기록)

- **당시 저장 덱: 대조용(원본 단일 불기둥).** Element 7 = Skill_FlamePillar
- 덱 8장·등록 순서·나머지 7장 그대로, `minGcd 0.4` / `interruptStagger 2.5` 그대로
- 적 구성 A+B+C 3체 모두 활성, `EnemyManager.enemies` 직렬화 목록은 원래대로 비어 있음(활성 오브젝트 자동 수집)
- 플레이어 `currentHp 500` / `resetHpOnStart` 켜짐, `Time.timeScale 1`
- Play 모드 종료, 씬 저장 완료(dirty 없음)
- 시험용 에셋은 삭제하지 않고 보존

이것은 구현 작업 종료 당시의 기록이다. 이후 제출 로그와 최신 저장 씬 확인은 [광역 1종 비교계측](260921_광역1종_비교계측.md) §1·§7 참조. 이 절로 현재 Unity 실행 중 덱을 단정하지 않는다.
