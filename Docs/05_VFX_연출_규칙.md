## 1. 원칙

> 시작 화면의 스크롤 문자 발광은 [10 A47](10_결정사항_로그.md#main-menu-20261008). 어두운 카툰풍 배경에서 문자가 푸르게 빛나며 양피지·가까운 테이블을 밝힌다. 문자와 주변 빛이 함께 잦아들며 전투 중에는 표시하지 않는다. 파일·조정은 [06](06_에셋_파이프라인.md#main-menu-assets).

> 이 게임에서 이펙트는 장식이 아니라 **읽어야 하는 신호**입니다.
> 플레이어는 이펙트의 모양이 아니라 **색과 소리**로 판단합니다.
> 무료 에셋을 재활용하더라도 색·강도·지속시간을 규칙으로 통일하면 일관성이 유지됩니다.

| 스케일 통일 | 타격 이펙트 기준 크기 [ ]유닛 |

### 6.1 1차 버전 2D 에셋 재활용

<!-- 게임 VFX의 상당수는 원래 카메라를 바라보는 평면(빌보드)입니다.
     3D 게임의 폭발·스파크 대부분이 실제로는 2D 이미지입니다. -->

| 단계 | 설정 |
|---|---|
| 1 | Particle System > Renderer > Render Mode = **Billboard** |
| 2 | Texture Sheet Animation 활성화 → 스프라이트 시트 행/열 지정 |
| 3 | 머티리얼 = Particles/Unlit, Blend Mode = **Additive**(발광) 또는 **Alpha**(연기·먼지) |
| 4 | Start Color는 스킬별 색을 따름. 적 캐스팅 표시의 3색 의미는 유지 |

**주의**
- 카메라가 거의 고정된 구도이므로 빌보드의 약점(측면에서 납작함)은 드러나지 않음
- 해상도가 낮은 시트는 3D에서 확대 시 뭉개짐 → 크게 쓰는 이펙트만 교체
- **1차 프로젝트 에셋의 사용 권한을 확인할 것** (팀원 제작분 / 구매 팩 라이선스) — `06_에셋_파이프라인` §5.1
