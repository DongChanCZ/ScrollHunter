## 1\. 난이도 곡선 설계

### 1.1 공격 구성과 교육 의도

**모든 적은 🟢 초록(기본 공격)을 가집니다.** 주황·빨강은 그 위에 **추가로** 얹히는 공격입니다.
상위 공격을 쓴 뒤에는 반드시 초록이 한 번 들어가므로, 플레이어는 대응 직후 숨 돌릴 틈을 얻습니다.

| 적 | 보유 공격 | 새로 가르치는 것 | 요구되는 대응 |
| :---- | :---- | :---- | :---- |
| 잡몹 A | 🟢 **초록만** | 대응이 필요 없는 공격의 존재 | 없음 (딜에 집중) |
| 잡몹 B | 🟢 \+ 🟠 | **차단 카드의 존재와 타이밍** | 차단 |
| 잡몹 C | 🟢 \+ 🔴 | **방어도 카드의 존재** | 방어 |
| 잡몹 D | 🟢 \+ 🟠 \+ 🔴 | 대응 카드가 둘 다 필요한 상황 \= **코스트 부족 체험** | 선택 |
| 보스 | 🟢 \+ 🟠 \+ 🔴 (패턴 다수) | 학습한 전부 \+ 페이즈별 비중 변화 | 덱 구성 자체가 시험됨 |

> **신규 요소는 한 번에 하나씩.** A는 상위 공격이 0개인 특수 케이스이며, 그 덕분에
> "대응할 필요가 없는 공격"을 먼저 보여줄 수 있습니다. 이것이 주황·빨강의 특별함을 만듭니다.

### 1.1.1 적 패턴 쿨다운 — 초록 횟수 기반 ★

<!-- 시간 기반 쿨다운은 플레이어에게 보이지 않아 예측이 불가능합니다.
     초록 횟수 기반이면 플레이어가 직접 셀 수 있습니다.
     주의: 플레이어 카드에는 쿨타임이 없습니다(10 문서 A항). 용어를 구분해 「적 패턴 쿨다운」이라 부릅니다. -->

| 공격 | 쿨다운 | 우선순위 |
| :---- | :---- | :---- |
| 🟢 초록 | **없음** (언제나 사용 가능) | 3 (최하) |
| 🟠 주황 | 사용 후 **초록 1회** 경과 필요 | 2 |
| 🔴 빨강 | 사용 후 **초록 2회** 경과 필요 | 1 (최상) |

**행동 선택 규칙**

1. 직전 행동이 상위 공격(🟠·🔴)이었다면 **반드시 초록을 사용**한다
2. 그 외에는 쿨다운이 끝난 공격 중 **우선순위가 가장 높은 것**을 사용한다
3. 사용 가능한 상위 공격이 없으면 초록을 사용한다

**D형(🟢🟠🔴) 순환 예시**

```
🔴 → 🟢 → 🟠 → 🟢 → 🔴 → 🟢 → 🟠 → 🟢 → 🔴 …
```

빨강 사용 후 초록 1회 시점에는 주황만 열려 있고, 초록 2회 시점에 빨강이 다시 열립니다.
**우선순위와 쿨다운 차이만으로 교대 패턴이 자동 생성**되므로 별도 스케줄링 로직이 필요 없습니다.

**차단당한 캐스팅도 쿨다운을 소모합니다.** (`10` M11)
차단당한 상위 공격은 「한 번 쓴 것」으로 치므로, 경직 2.5초가 끝나면 반드시 초록이 먼저 옵니다.

```
🟠 (차단당함) → 2.5초 경직 → 🟢 → 🟠
```

쿨다운을 소모시키지 않으면 경직이 풀리자마자 같은 주황이 다시 올라와 차단의 보상이 「2.5초 지연」뿐이 됩니다.
소모시키면 **초록 한 번만큼의 안전 구간이 추가로** 생깁니다.

단 **초록을 차단한 경우에는 초록 횟수를 올리지 않습니다.** (`10` M12)
초록 횟수는 플레이어가 화면에서 직접 세는 값이라, 취소되어 발동하지 않은 캐스팅을 세면 어긋납니다.

> **플레이어가 셀 수 있다는 것이 핵심입니다.** "초록 두 번 지났으니 다음은 빨강"을 예측할 수 있어야
> 대응 카드를 언제 아껴둘지 판단이 섭니다. 카드의 결정론적 순환과 같은 철학입니다.
