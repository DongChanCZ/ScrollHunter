## 1\. 난이도 곡선 설계

### 1.1 공격 구성과 교육 의도

**모든 적은 🟢 초록(기본 공격)을 가집니다.** 주황·빨강은 그 위에 **추가로** 얹히는 공격입니다. 일반 적은 상위 공격을 쓴 뒤 초록이 한 번 들어가므로, 플레이어는 대응 직후 숨 돌릴 틈을 얻습니다.

| 적 | 보유 공격 | 새로 가르치는 것 | 요구되는 대응 |
| :---- | :---- | :---- | :---- |
| 튜토리얼 \- 깡패 | 10 A32 참조 | 게임 조작·색별 대응 연습 | 상세 안내·순서는 §2.1에서 작성 |
| 잡몹 A \- 약탈자 | 🟢 **초록만** | 대응이 필요 없는 공격의 존재 | 없음 (딜에 집중) |
| 잡몹 B \- 궁병 | 🟢 \+ 🟠 | **차단 카드의 존재와 타이밍** | 차단 |
| 잡몹 C \- 우두머리 | 🟢 \+ 🔴 | **방어도 카드의 존재** | 방어 |
| 잡몹 D | 🟢 \+ 🟠 \+ 🔴 | 대응 카드가 둘 다 필요한 상황 \= **코스트 부족 체험** | 선택 |
| 보스 \- 마법사 | 🟢 \+ 🟠 \+ 🔴 (패턴 다수) | 학습한 전부 \+ 페이즈별 비중 변화 | 덱 구성 자체가 시험됨 |

> 위 A\~보스의 교육 의도는 초기 설계 메모. 새 구성은 튜토리얼에서 먼저 조작을 배우는 방식(10 A32). 튜토리얼 학습·재도전·스킵은 구현됨. 보스는 10 A34로 구현. 목표 시간의 빈칸은 유지.

### 1.1.1 적 패턴 쿨다운 — 초록 횟수 기반 ★

일반 적 기준. 튜토리얼은 [10 A32](10_결정사항_로그.md#tutorial-learning-20260929), 보스는 [10 A34](10_결정사항_로그.md#boss-phases-20260930)의 예외를 따른다.

| 공격 | 쿨다운 | 우선순위 |
| :---- | :---- | :---- |
| 🟢 초록 | **없음** (언제나 사용 가능) | 3 (최하) |
| 🟠 주황 | 사용 후 **초록 1회** 경과 필요 | 2 |
| 🔴 빨강 | 사용 후 **초록 2회** 경과 필요 | 1 (최상) |

**행동 선택 규칙**

1. 직전 행동이 상위 공격(🟠·🔴)이었다면 **반드시 초록을 사용**한다  
2. 그 외에는 쿨다운이 끝난 공격 중 **우선순위가 가장 높은 것**을 사용한다  
3. 사용 가능한 상위 공격이 없으면 초록을 사용한다

**D형(🟢🟠🔴) 순환 예시**

🔴 → 🟢 → 🟠 → 🟢 → 🔴 → 🟢 → 🟠 → 🟢 → 🔴 …

빨강 사용 후 초록 1회 시점에는 주황만 열려 있고, 초록 2회 시점에 빨강이 다시 열립니다. **우선순위와 쿨다운 차이만으로 교대 패턴이 자동 생성**되므로 별도 스케줄링 로직이 필요 없습니다.

**차단당한 캐스팅도 쿨다운을 소모합니다.** (`10` M11) 차단당한 상위 공격은 「한 번 쓴 것」으로 치므로, 경직 2.5초가 끝나면 반드시 초록이 먼저 옵니다.

🟠 (차단당함) → 2.5초 경직 → 🟢 → 🟠

쿨다운을 소모시키지 않으면 경직이 풀리자마자 같은 주황이 다시 올라와 차단의 보상이 「2.5초 지연」뿐이 됩니다. 소모시키면 **초록 한 번만큼의 안전 구간이 추가로** 생깁니다.

단 **초록을 차단한 경우에는 초록 횟수를 올리지 않습니다.** (`10` M12) 초록 횟수는 플레이어가 화면에서 직접 세는 값이라, 취소되어 발동하지 않은 캐스팅을 세면 어긋납니다.

> **플레이어가 셀 수 있다는 것이 핵심입니다.** "초록 두 번 지났으니 다음은 빨강"을 예측할 수 있어야 대응 카드를 언제 아껴둘지 판단이 섭니다. 카드의 결정론적 순환과 같은 철학입니다.

### 1.1.2 발동 후 경직

> **구현·실측 확인 (2026-09-17, Claude 기록).** 발동 후 경직은 아래 색별 값이며 별도 하위 경직 구간은 없다.

| 공격 | 발동 후 경직 | 근거 |
| :---- | :---- | :---- |
| 🟢 초록 | 1.0초 | 현행 행동 간격 유지 |
| 🟠 주황 | 1.5초 | 대응 직후 여유 |
| 🔴 빨강 | 2.0초 | 가장 김 |
| 차단 성공 시 | 2.5초 | §3.2. 피해 없는 차단 카드의 이득 |

"경직 해제 → 다음 캐스팅 시작"이 아니라 **경직 시간 \= 다음 캐스팅까지의 간격**입니다.
