### 1.1 기대치 조정

> 생성형 3D는 아티스트를 대체하지 않습니다. 얻는 것은 "아트가 있는 팀 수준의 결과물"이 아니라 **"설계한 것을 그릴 수 있는 자유"**입니다.

| 해소되는 아쉬움 | 해소되지 않는 것 |
|---|---|
| 원하는 역할의 적을 만들 수 있음 | 스타일 통일 (회차마다 편차) |
| 실루엣으로 역할을 구분할 수 있음 | 리깅·애니메이션 |
| 팩에 없는 것을 포기하지 않아도 됨 | 토폴로지·폴리곤 품질 |
| | 모델당 1~2시간의 정리 비용 |

- 궁병 사망: `Animations/Archer/Mixamo/MX_StandingDeathBackward01.fbx.meta`의 BowDraw 추가 곡선을 정규화 시간0~1·값0으로 수정. `ArcherAnimationBuilder.SetMixamoImport`의 Death도 같은 값 적용. 원본 FBX·0~77프레임·다른 동작 유지.

씬 `BattleEnvironment` 아래 4개 배경, `BattleEnvironment` 컴포넌트에서 전투별 전환·마법진 확대·회전·보라 발광. Circle Degrees Per Second·Glow Period·Glow로 조절, 재질은 실행 중 PropertyBlock으로 표시하며 공유 원본을 바꾸지 않음. 배치는 자식 Transform에서 조정. `Build Battle Backgrounds`는 없는 씬에 최초 생성할 때만 사용하며 기존 배경이 있으면 중단한다. FBX를 따로 재배치할 때 원본의 X=-90° 축 보정을 지우지 말 것.

10/7 색 보정: 숲·입구의 갈색을 청록·청회색으로 낮추고 보스 동굴은 더 어둡게 조정. `Environment/Materials`의 배경 4개·소품 7개 `_BaseColor`와 `BattleEnvironmentSetup` 색 배열을 함께 유지. 적 재질·전역 조명은 유지. 전후 값·화면은 [07](07_개발일지.md#d15-background-color).

후속 일반 맵 가시성은 [10 A45](10_결정사항_로그.md#outdoor-readability-20261007). 튜토리얼 후속은 하늘·풀밭 배경을 더 밝고 따뜻하게 조정. 나무·바위는 앞선 가시성 보정 유지. 일반 바위는 `P04_MossRocks_Outdoor`, 보스 바위는 기존 `P04_MossRocks`. `BattleEnvironmentSetup`의 PropTints·BackplateTints·OutdoorRockTint와 씬 나무 좌표·입구 폭을 같이 유지. 결과는 [07](07_개발일지.md#d15-outdoor-readability).
