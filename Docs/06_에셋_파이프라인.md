## 1. 이번 프로젝트에서 생성형 3D를 쓰는 이유

<!-- "수업 조건이라서"만 적으면 약합니다. 설계상의 이유를 함께 적으세요. -->

| 항목 | 내용 |
|---|---|
| 형식 요건 | 수업 조건: VARCO 3D를 게임 요소에 활용할 것 |
| **설계상의 이유** | **1차 프로젝트는 팀에 아트 인원이 없어 기존 에셋 팩만으로 제작했고, 그 결과 설계가 에셋을 따라갔다** (`01_회고` §4.5) |
| 1차의 근거 | 맵 문서의 몬스터가 `이미지 코드 138 / 166 / 147 / 111 / 142`로 관리됨 — 에셋 팩 번호 |
| 이번 변경 | **적 설계 → 에셋 생성** 순서로 전환. 담당 색상(🟢🟠🔴)에서 출발해 외형을 정함 |
| 이 게임과의 적합성 | 텔레그래프가 애니메이션이 아닌 **캐스팅 바(UI)**에 있으므로, 모션 없는 정지 메시로도 시스템이 성립 |
| 카메라 구도의 이점 | 고정 카메라 + 적이 화면의 주인공. 인간형이 아니어도 되는 적에 생성 AI가 가장 잘 맞음 |

### 1.1 기대치 조정

> 생성형 3D는 아티스트를 대체하지 않습니다. 얻는 것은 "아트가 있는 팀 수준의 결과물"이 아니라 **"설계한 것을 그릴 수 있는 자유"**입니다.

| 해소되는 아쉬움 | 해소되지 않는 것 |
|---|---|
| 원하는 역할의 적을 만들 수 있음 | 스타일 통일 (회차마다 편차) |
| 실루엣으로 역할을 구분할 수 있음 | 리깅·애니메이션 |
| 팩에 없는 것을 포기하지 않아도 됨 | 토폴로지·폴리곤 품질 |
| | 모델당 1~2시간의 정리 비용 |

## 2. 설계 → 생성 매핑

<!-- 이 표를 먼저 채우고 나서 프롬프트를 씁니다. 역순으로 하면 1차의 실수를 반복합니다. -->

## 3. 프롬프트 관리

### 3.1 프롬프트 보존

공통 방향은 10 A37·A39. 실제 입력은 [약탈자](근거자료/2026-10-01_적모델링/01_약탈자_생성프롬프트.txt)·[궁병](근거자료/2026-10-01_적모델링/03_궁병_생성프롬프트.txt)에 보존했다. 궁병은 약탈자 이미지를 스타일 참조로 사용했다. 생성 결과가 목표 스타일에 맞는지는 게임 화면에서 별도 확인한다.

### 3.2 생성 기록

| 대상 | 생성·후처리 | 최종 채택 | 기록 |
|---|---|---|---|
| 약탈자 | 이미지→3D→VARCO 손가락 리깅 | 미확정 | [07 약탈자](07_개발일지.md#d12-raider-model) |
| 궁병 | 이미지→3D→Blender 손 분리→임시 옷 자세 검사 | 미확정 | [07 궁병](07_개발일지.md#d12-archer-image)·[옷 검사](07_개발일지.md#d12-archer-cloak) |

보존 위치는 `근거자료/2026-10-01_적모델링/`. VARCO 원본과 Blender 수정본을 분리한다. 외부 수정본을 VARCO 워크플로에 다시 올리는 경로는 미확인이다. `3DInput` 노드 존재만으로 로컬 파일 업로드 가능하다고 판단하지 않는다.

### 5.2 무료 UI 에셋 적용 절차 (2026-10-01)

디자인 원본은 [10 A37 후속](10_결정사항_로그.md#resource-hud-20261001). 10/1 적용: 신규는 Ravenmore 아이콘 팩(CC-BY 3.0)의 빨강 물약·금속 방패 2종뿐이고, 게이지 테두리·끝 장식·포션 칸·마커 문양은 기존 RPG GUI 아틀라스에서 분리, 구분선은 기존 Kenney 팩에서 추가 반입, 사선 모서리 버튼은 기존 판 버튼을 가공해 합성. 출처·가공은 [CREDITS](CREDITS.md), 위치·확인은 [07 D-12](07_개발일지.md#d12-ui-design).

| 순서 | 작업 |
|---|---|
| 1 | 현재 RPG GUI·Kenney 테두리·양피지·아이콘부터 확인. 유지할 스킬 프레임·아이콘은 교체하지 않음. 폰트는 10 A37 후속 승인 범위만 변경. 양피지는 10/1 사용자 정정으로 설명 패널에 쓰지 않음 |
| 2 | 부족한 게이지·방패·물약·정보창 자료만 무료로 검색. 무료 배포 여부와 수정·게임 배포 허용 조건을 원본 페이지에서 확인 |
| 3 | 조건이 명확한 CC0·CC BY 자료 우선. 유료 체험·워터마크·재배포 출처 불명 자료 제외. 권한이 불명확하면 기존 자료로 대체 |
| 4 | 필요한 파일만 임포트. 전용 폴더에 출처·라이선스 원문 보존. 기존 파일 삭제·패키지 일괄 덮어쓰기 금지 |
| 5 | 기존 테두리와 색·선 두께·질감 통일. 실제 사용분만 CREDITS에 제작자·원본 URL·라이선스·가공 내역 기록 |
| 6 | 적용 전후 화면·사용 위치·확인 결과는 07 D-12. 사용 에셋 표는 실제 적용 후 갱신 |

레퍼런스 게임은 형태·배치 참고용이다. 게임 화면에서 추출한 이미지를 에셋으로 사용하지 않는다.

## 6. 발생한 문제와 대응 기록
