### 2.1 분류별 설계 지침

| 분류 | 지침 |
| :---- | :---- |
| 딜 | 코스트당 기대 피해량이 가장 높아야 함. 대신 대응 불가. **카드에 적힌 피해량이 곧 실제 수치** |
| 차단 | **딜이 낮거나 없어야 함.** 딜까지 높으면 무조건 채용되어 선택이 사라짐 |
| 방어 | 코스트 대비 흡수량이 커야 함. 대신 적을 죽이지 못해 전투가 길어짐 |

> **함정 회피:** 차단·방어 카드에 딜을 붙이면 "대응하면서 딜도 된다"가 되어 트레이드오프가 소멸합니다. 대응 카드는 **딜을 포기하는 대가**여야 합니다.

### 2.2 캐스팅 시간이라는 두 번째 축 ★

카드를 쓰면 `MAX(시전 또는 채널링 시간, 최소 GCD 0.4초)` 동안 다른 카드를 쓸 수 없습니다. 따라서 **그동안 다른 카드를 선택할 수 없다는 점**이 코스트와 별개의 비용입니다. 일반 시전은 효과가 나올 때까지 기다리지만, 채널링은 진행 중인 효과도 함께 평가해야 합니다. 공통 규칙은 `10` A1·A11·A18을 따릅니다.

| 유형 | 캐스팅 | 설계 방향 |
| :---- | :---- | :---- |
| 짧은 시전·고코스트 | 0.2\~0.4초 | 효과까지의 대기가 짧음. 위기 대응용 |
| 일반 시전·고위력 | 0.8\~1.5초 | 효과가 나올 때까지 다른 카드 사용을 포기 |
| 차단 | 0.2\~0.3초 | **반드시 짧게.** 길면 시스템이 성립하지 않음 |
| 방어 | 0.2\~0.3초 | **반드시 짧게** |

> 위 시간 범위는 기존 일반 시전의 설계 예시입니다. **즉발은 일반 시전 시간이 0초인 경우**이며, 채널링의 지속시간 범위를 이 표로 확정하지 않습니다.  
>   
> **밸런스는 두 축을 함께 봐야 합니다.** 코스트당 기대 피해가 같아도, 캐스팅 1.2초 카드는 즉발 카드보다 0.8초의 대응 불가 시간을 추가로 지불합니다. 엑셀 `스킬` 시트의 **`코스트당 기대 피해`와 `시간당 기대 피해`가 모두** 고르게 나와야 진짜 균형입니다. 한쪽만 맞추면 무조건 채용되는 카드가 생깁니다.

### 2.2.1 발동 방식 구분 (2026-09-21)

공격·차단·방어라는 **효과 분류**와 별도로 **일반 시전 / 채널링**을 선택한다. 채널링의 정의·중단·종료 규칙은 [10 A18](http://10_결정사항_로그.md#channeling-definition)에 한 벌로 관리한다. 기존 카드가 자동으로 채널링으로 바뀌지는 않는다.

채널링은 **시전하는 동안 효과를 유지하거나 발생시키며, 그동안 다른 스킬을 쓸 수 없는 방식**이다(`10` A18). 채널링의 가치는 완료 시 총효과뿐 아니라 진행 중 얻은 효과와 다른 카드 사용을 포기한 시간을 함께 본다. 예를 들어 피해를 나누어 발생시키는 경우에는 첫 피해 시점과 발생 간격도 설계 요소다.

각 SK 표의 **발동 방식**과 **시전 / 채널링 시간**을 기입한다. 시간 칸은 일반 시전이면 효과 적용까지의 시간, 채널링이면 효과를 유지·발생시키는 기간을 뜻한다. 부가 효과나 방어도의 유지시간과는 구분한다. 채널링을 선택한 카드만 [채널링 상세 작성 양식](#channeling-skill-template)을 해당 SK 표 아래에 복사해 작성한다. 일반 시전은 채널링 상세를 「해당 없음」으로 적는다. 새 발동 방식이므로 스킬 풀 14종에 별도 분류나 장수를 더하지 않는다.

기절·정지·종료의 공통 처리는 `10` A18을 참조하며 카드마다 전문을 복사하지 않는다. 무적·면역 등 별도 기능이 필요하면 그 카드의 제안 기능과 구현 상태를 따로 기록한다. 실제 연결 방법은 [09 채널링 제작](http://09_프로토타입_제작절차.md#channeling-authoring) 참조. 이번 양식 보완은 개별 수치·효과의 확정이나 구현 완료를 뜻하지 않는다.

### 2.3 단일 / 광역 설계 ★

**손익분기: 적 2체.** 같은 코스트라면 광역 피해량은 단일 피해량의 **절반**입니다.

| 유형 | 피해량 | 적 1체 | 적 2체 | 적 3체 |
| :---- | :---- | :---- | :---- | :---- |
| 단일 | 120 | **120** | 120 | 120 |
| 광역 | 60 | 60 | **120** | **180** |

> **주의: 코스트를 올리면 손익분기가 무너집니다.** 광역기의 코스트를 2배로 올렸다면 피해량도 2배여야 같은 손익분기가 유지됩니다. 단일 120 @ 코스트 3 ↔ 광역 120 @ 코스트 6 이 2체에서 동등합니다. 피해량만 절반으로 두고 코스트까지 올리면 광역기가 모든 구간에서 열등해집니다.

#### 대가는 코스트가 아니라 캐스팅 시간으로

광역기가 "적이 많을수록 위험한 선택"이 되도록, **대가를 캐스팅 시간에 싣습니다.**

| 유형 | 캐스팅 | 잠금 |
| :---- | :---- | :---- |
| 단일 | 0.3초 | 0.4초 |
| 광역 | 0.8\~1.2초 | 0.8\~1.2초 |

적이 3체일 때는 위협도 3배입니다. 그런데 광역기를 쓰면 **1.2초 동안 대응할 수 없습니다.** "쓸어버릴까, 위험하니 짧은 단일로 갈까"가 생깁니다. 코스트로 막으면 그냥 못 쓰는 것이지만, 캐스팅으로 막으면 위험을 감수하는 결정이 됩니다.

#### 보스전에서의 격차

| 전투 | 적 수 | 광역 가치 |
| :---- | :---- | :---- |
| 1\~3 | 2 | 단일과 동등 |
| 4 | 3 | 단일의 1.5배 |
| 5 (보스) | **1** | **단일의 절반** |

**덱 8장 고정 구조에서 이 격차가 결정을 만듭니다.** 광역기를 여러 장 넣으면 잡몹전이 편해지지만 보스전에서 손패 절반이 죽은 카드가 됩니다.

밸런스시트 `스킬` 시트의 **`코스트당 (보스)`와 `코스트당 (잡몹)`** 두 열의 격차로 확인하세요. 격차가 크면 상황용, 없으면 범용입니다.

### 2.4 덱 순서와 캐스팅 시간

앞쪽 슬롯에 캐스팅 긴 카드를 몰아두면, 코스트가 넘쳐도 뒤쪽 대응 카드를 빨리 끌어올 수 없습니다. **덱 순서 자체가 설계 결정입니다.** `덱시뮬` 시트의 `코스트 충분 시 최소 대기` 열로 확인하세요.

### 채널링 상세 작성 양식 — 선택한 SK 표 아래에 복사

| 항목 | 내용 |
| :---- | :---- |
| 적용 스킬 ID | \[ SK 번호 \] |
| 시작 시 효과 | \[ 시작 즉시 적용할 효과·수치 / 없음 \] |
