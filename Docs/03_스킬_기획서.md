## 2. 스킬 풀 구성

<!-- 14종. 덱은 이 중 8장. 분류별 장수가 덱 구성의 트레이드오프를 만듭니다. -->

| 분류 | 개수 | 역할 | 대응 색상 |
|---|---|---|---|
| 딜 (단일) | [ 4 ] | 주력 피해 | — |
| 딜 (광역) | [ 4 ] | 다수 적 처리 | — |
| 차단 (인터럽트) | [ 3 ] | 캐스팅 취소 | 🟠 주황 |
| 방어 (방어도) | [ 3 ] | 쉴드 부여 | 🔴 빨강 |
| **합계** | **14** | | |

### 2.1 분류별 설계 지침

| 분류 | 지침 |
|---|---|
| 딜 | 코스트당 기대 피해량이 가장 높아야 함. 대신 대응 불가 |
| 차단 | **딜이 낮거나 없어야 함.** 딜까지 높으면 무조건 채용되어 선택이 사라짐 |
| 방어 | 코스트 대비 흡수량이 커야 함. 대신 적을 죽이지 못해 전투가 길어짐 |

> **함정 회피:** 차단·방어 카드에 딜을 붙이면 "대응하면서 딜도 된다"가 되어 트레이드오프가 소멸합니다. 대응 카드는 **딜을 포기하는 대가**여야 합니다.

### 2.2 캐스팅 시간이라는 두 번째 축 ★

카드를 쓰면 `MAX(캐스팅 시간, 최소 GCD 0.4초)` 동안 다른 카드를 쓸 수 없습니다. (02 문서 §4.1)
따라서 **캐스팅 시간은 "그동안 적에게 대응할 수 없는 시간"**이며, 코스트와 별개의 비용입니다.

| 유형 | 캐스팅 | 설계 방향 |
|---|---|---|
| 즉발 고코스트 | 0.2~0.4초 | 비싸지만 언제든 낼 수 있음. 위기 대응용 |
| 캐스팅 고위력 | 0.8~1.5초 | 싸고 강하되, 그 시간 동안 무방비 |
| 차단 | 0.2~0.3초 | **반드시 짧게.** 길면 시스템이 성립하지 않음 |
| 방어 | 0.2~0.3초 | **반드시 짧게** |

> **밸런스는 두 축을 함께 봐야 합니다.**
> 코스트당 기대 피해가 같아도, 캐스팅 1.2초 카드는 즉발 카드보다 0.8초의 대응 불가 시간을 추가로 지불합니다.
> 엑셀 `스킬` 시트의 **`코스트당 기대 피해`와 `시간당 기대 피해`가 모두** 고르게 나와야 진짜 균형입니다.
> 한쪽만 맞추면 무조건 채용되는 카드가 생깁니다.

### 2.3 덱 순서와 캐스팅 시간

앞쪽 슬롯에 캐스팅 긴 카드를 몰아두면, 코스트가 넘쳐도 뒤쪽 대응 카드를 빨리 끌어올 수 없습니다.
**덱 순서 자체가 설계 결정입니다.** `덱시뮬` 시트의 `코스트 충분 시 최소 대기` 열로 확인하세요.

## 5. 보상 (3택1)

### 5.1 기본 규칙

| 항목 | 규칙 | 근거 |
|---|---|---|
| 제시 개수 | 3 | 1차 버전 계승 |
| 구성 | **카드 2 + 패시브 1** | 카드는 대가(1장 교체)가 있고 패시브는 없음 |
| 중복 허용 | 불가 (카드), 허용 (패시브 스택) | [ ] |
| 스킵 | **허용** (덱 유지) | 매번 강제로 넣으면 덱이 의도치 않게 망가짐 |
| 카드 선택 시 | 덱 편성 화면으로 → 뺄 카드 1장 선택 | **덱은 항상 8장** |
| 뺀 카드 | **영구 소멸** (인벤토리 없음) | 관리 UI를 늘리지 않고 결정을 무겁게 유지 |
| 패시브 선택 시 | 즉시 적용 후 다음 전투 | [ ] |
| 상한 도달 패시브 | 추첨 풀에서 자동 제외 | 회색 처리보다 안 보이는 쪽이 깔끔 |

### 5.2 등장 보정 (교육 곡선 연동)

| 보상 시점 | 카드 2장 구성 | 의도 |
|---|---|---|
| 전투 1 클리어 후 | 딜 1 + **차단 1 (고정)** | 전투 2에서 주황 적을 만남 |
| 전투 2 클리어 후 | 딜 1 + **방어 1 (고정)** | 전투 3에서 빨강 적을 만남 |
| 전투 3 클리어 후 | 무작위 2 | 자유 |
| 전투 4 클리어 후 | 무작위 2 | 보스 대비 |

> 초반 2회를 고정해 대응 카드를 못 뽑아 막히는 사고를 방지합니다. 후반 2회는 열어서 자유도를 줍니다.
