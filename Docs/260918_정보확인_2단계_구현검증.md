# 2026-09-18 후속 2단계 — 카드·적 공격 정보와 일시정지

사용자가 Claude 대신 Codex에 구현을 맡겼으며 이번 작업에 한해 프로젝트 코드·씬 변경을 허용했다. 원시 계측·임시 카드 수치·덱·적 구성은 변경하지 않았다. 3단계 광역 설계·구현은 진행하지 않았다.

## 사용 방법

1. Battle 씬을 Play한다. 추가 배치 작업은 없다.
2. 손패에 마우스를 올리면 오른쪽에 현재 카드 정보가 표시된다. 손패 좌클릭은 해당 QWER과 동일하게 카드를 사용한다(10 A17).
3. 손패를 우클릭하면 전투가 정지하고 해당 정보를 유지한다. 정지 중 다른 카드에 마우스를 올리면 설명만 바뀐다.
4. 다시 우클릭하거나 좌측 상단 재개 영역을 클릭하면 이어서 진행한다. 좌측 상단 일시정지 영역으로도 정지할 수 있다.
5. 선택한 적의 현재 공격은 좌측 정보창에서 읽는다. 방향키·적 클릭으로 대상을 바꾸면 정보도 바뀐다. 비캐스팅 중에는 이전 공격 대신 현재 시전 중인 공격 없음을 표시한다.
6. 승리·패배 후에는 정보창을 숨기고 전투 종료를 표시한다. 재개 및 카드 사용은 막힌다.

## 변경 파일

- `Assets/_Project/Scripts/CombatInfoUI.cs` 및 `.meta`: 현재 데이터에서 설명 생성, 마우스 위치로 손패·정지 영역 판별, 정보 확인용 정지·재개. 표시 문자열·UI 참조는 직렬화 필드다.
- `DeckSystem.cs`: 기존 interruptStagger 읽기 접근자, 정지·승패 종료 시 TryUseSlot 직접 호출도 거절하는 보호 조건.
- `Enemy.cs`: 정지·전투 종료·플레이어 사망 시 공격 진행 중단. 캐스팅이 끝난 대기 프레임에서 정지해도 발동하지 않도록 Update 입구에서 검사.
- `EnemyManager.cs`: UI 위 클릭이 뒤의 적 타겟 변경으로 전달되지 않도록 EventSystem 검사.
- `Assets/_Project/Scenes/Battle.unity`: Canvas/CombatInformation, 일시정지 영역·조작 안내·카드 정보창·타겟 정보창과 참조 연결.
- `Assets/_Project/Fonts/GmarketSansMedium SDF.asset`: 기존 동적 TMP 폰트에 새 설명용 글리프가 생성되어 변경됨. 새 폰트 도입 아님.

## 후속 추가: 손패 좌클릭 사용 (2026-09-18)

사용자 요청으로 CombatInfoUI.Update의 좌클릭 분기에서 hovered 슬롯을 기존 DeckSystem.TryUseSlot으로 전달한다. 정지 버튼을 먼저 처리하고 우클릭 동작은 유지한다. 별도 씬 연결은 필요 없다. 사용 로그의 QWER 표기는 슬롯 이름이며 입력 장치 구분 기록은 아니다.

Unity Play 함수 호출 확인: 화염탄 사용 성공, 코스트 3→1, 같은 슬롯 카드 순환 및 시전 시작. 행동 잠금·일시정지·기절 중 추가 사용 거절 및 코스트 유지 확인. 기존 공통 함수의 코스트 부족·대상·종료 조건을 재사용하며 이번에 해당 조건을 별도 재시험하지 않았다. 실제 마우스 클릭 경로는 미확인. 시험 후 Play 종료, 런타임 기절은 저장하지 않음.
